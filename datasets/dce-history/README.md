# 大商所官方历史文件

决策依据见 `docs/DECISIONS.md` 的 `DEC-044`。

## 这是什么

大连商品交易所官网历史数据下载页发布的**年度逐合约行情文件**，未经修改。
每个 xlsx 一个工作表「日历史行情」，列为：商品名称、合约名称、交易日期、开盘价、
最高价、最低价、收盘价、前结算价、**结算价**、涨跌、涨跌1、成交量、持仓量、
持仓量变化、成交额。

`quotes/` 当前覆盖焦煤与鸡蛋 2013–2018，共 30,413 行逐合约日行情：

| 品种 | 起 | 交易日 |
| --- | --- | --- |
| 焦煤 jm | 2013-03-22（上市首日） | 2013:188 / 2014:245 / 2015:244 / 2016:244 / 2017:244 / 2018:243 |
| 鸡蛋 jd | 2013-11-08（上市首日） | 2013:38 / 2014:245 / 2015:244 / 2016:244 / 2017:244 / 2018:243 |

## 为什么要它

这些年份**没有任何在线接口能提供**（2026-08-09 实证）：

- 大商所官方 API 自 2026-08-02 起对所有客户端返回 412
- 新浪只保留到约 2018-09（`JM1909` 有，`JM1801`/`JM1901` 空）
- 东方财富一条退市合约都不保留
- 三禾逐合约只有 2026-01 起 7 个月

而交易所官网自己的历史下载页从 2006 年起一直挂着，且**带结算价**——这是唯一
能同时满足深度与完整性的来源。

## 怎么取得的，以及为什么不自动化

**由 Claude 操作运营者的 Chrome 一次性下载（运营者指示，非运营者本人操作）。** 该站 WAF 拒绝脚本客户端（VPS 上 curl 同一 URL
仍返回 412），**不得为此编写任何绕过机器人检测的代码**。

这对本数据成立，是因为**历史不可变**：一次取得后永远正确。同样的做法**不适用于
每日采集**——那必须走 `DEC-041` 的官方优先 / 新浪兜底链路。

## 怎么用

采集器把它当本地文件源读，不打开任何套接字（数据源 `dce_official_history` 的
域名白名单为空，将来若有人试图从这里发请求，出站围栏会直接拒绝）：

```bash
FUTURES_DCE_HISTORY_DIR=/srv/dce-history \
  collector --date 2015-09-01 --exchange DCE --variety JM,JD --dce-history
```

落库仍走既有导入通道，按交易日一批（catalog → calendar → market），审计批次、
来源标注、RLS 全部复用。回填驱动 `run-backfill.sh` 可直接驱动。

**本源不承担席位。** 这些年份的席位在交易所的日排名归档里
（`/dcereport/publicweb/dailystat/memberDealPosi/batchDownload`，实测 2013-06-14
可得），属另一次一次性取得。

## 完整性

`quotes/SHA256SUMS` 是权威清单。文件放到机器上之后应当核对：

```bash
cd /srv/dce-history && sha256sum -c SHA256SUMS
```

仓库是记录，机器上那份靠校验和对齐——避免出现「仓库有、机器上没有」或反过来的情况。
