# 预注册:卸仓门在「区间上沿」放宽(纯碱 / 玻璃)

立项日 2026-09-06。运营者 09-05~09-06 的原话:「条件1没问题,**条件3需要约束**,
条件2比较麻烦…本质是确定趋势,确定机构要做空的初步阶段进行进场,机构是逐步加仓的,
而我们的策略是一次性进去,天然的冲突」;收口指令:「开始跑你定完的3点,**看看回撤有没有降低**」。
**本文在写跑数脚本之前写完并提交**;跑完不许回来改本文,
只许在 `REPORT_SA_UNLOAD_GATE_v1` 里如实报。

## 一、立项前的测量(已做完,数字照抄进本文,报告里不许改)

轮高点定义(测量用,后视):结算价在前后各 20 日内最高,且此后 60 日内回落 ≥6%,
同 40 日内只留最高的一个。纯碱 2020-06 起 14 个,玻璃 2013-01 起 40 个。

**① 运营者「四五成仓」的判断成立。** 纯碱 5 个「高点当天机构已净空」的轮高点上,
机构净空占**本轮最终峰值**的比例为 71% / 49% / 37% / 60% / 50%,**中位 50%**。
玻璃 19 个同类高点中位 27%(**品种间不一致**,不可当跨品种常数)。

**② 「一次性进 vs 机构逐步加」的冲突量化了。** 现行成本进场的做空笔,
进场时机构已建到本轮最终峰值的**中位 70%**(纯碱,四分位 47%~91%;玻璃 71%),
距最近前高**中位 52 个交易日**(玻璃 42 日)。

**③ 条件2 不是滞后的原因 —— 运营者这一点的方向反了。**
高点当天「价 ≥ 机构空头成本」**纯碱 5/5、玻璃 20/20 全部满足**
(溢价 +2.5%~+13.3%)。它卡人是在下跌途中(价跌破成本那段),不是在高点。
**因此本次不动条件2。**

**④ 真正把进场推到末期的是条件3。** 纯碱 5 个高点里 **3 个**被
「机构本轮已卸掉 40% / 63% / 40%(超过 30% 不追)」挡掉;玻璃 20 个里 17 个同因。
机理:`unload` 的分母是**本轮 running peak**,价格反弹到高点时机构净空缩水,
`unload` 假性冲高 → 引擎读成「机构在出货」。**而那正是新一轮加空的起点。**

**⑤ 区间位置能把两者分开。** 轮高点当天 `pos_20` 中位 **0.91**、最小 **0.80**、
100% ≥0.6;现行做空进场日 `pos_20` 中位只有 **0.50**,仅 40% ≥0.6。
(2026-09-03 那笔实测 `pos_10` = 0.31。)

**⑥ 两条被测量否掉、本次明确不加的:**
- **趋势确认单独用没有边际**:可实盘版(现价 ≤ 近 60 日最高 ×0.94)确认后,
  纯碱机构净空的 20 个确认日之后 20 日中位 **+1.1%**(做空只胜 9/20),
  40 日 −2.6%(13/20);玻璃 −0.3% / −1.5%。**不做扳机,本次也不做门。**
- **「几成仓」做不成规则**:可实盘的水位口径(占近 500 日最大净持仓的几成)
  在高点上纯碱中位 37% / 玻璃 15%,而**现行进场日也是 38% / 20%** —— 同分布,分不开。
  能分开的「占本轮**最终**峰值」是后视量,实盘取不到。

## 二、假设(只有一条)

**H1**:把成本进场的**条件3**从

```
unload ≤ umax(纯碱 umax = 0.30)
```

改成

```
unload ≤ umax   或   ( pos_20 ≥ p  且  unload ≤ ucap )
```

其中 `pos_20 = (结算价 − 近 20 日最低) / (近 20 日最高 − 近 20 日最低)`。
**这不是新加一个过滤器,是修一个能指名道姓的缺陷**(第一节④):
高 `unload` 在区间上沿的含义与在下跌途中不同,现行规则不分这两种情形。

## 三、参数(事前写死,只有一个旋钮)

- `ucap = 0.60` **固定,不扫**。理由事前写明:0.60 覆盖第一节④里三个被误挡高点中的两个
  (40%、40%),63% 那个覆盖不到 —— **接受漏掉它**,换「卸掉超过六成就是真出货」这条界线。
  **跑完不许回来扫 ucap。**
- `p ∈ {0.6, 0.7, 0.8}` —— **就这 3 格**。上界 0.8 取自「高点当天 pos_20 最小 0.80」。
  **代表格事前指定 `p = 0.7`**,主数字报它,不许跑完挑最好的那格报。
- 出场四件套(散户翻向 / 止损 6% / 持满 40 日 / 临近交割)**一字不动**;
  条件1、条件2、`cost_min_age`、`cost_need_adding` 全部不动;
  `retail_seed` 用当前生产值(DEC-211:纯碱 徽商/方正中期/中信建投,玻璃 中信建投/平安/广发)。
- 全样本 `replay_start` 起(纯碱 2020-06、玻璃 2013-01)。**不换窗口** ——
  2024 起的那份是探索性副产品,不作判定。
- 实现口径:**不重写 `cost_entry_frame`**。把 `unload` 序列在
  `pos_20 ≥ p 且 unload ≤ ucap` 的日子上置 0,再原样调生产的 `cost_entry_frame`
  —— 该函数对 `unload` 只有 `u > umax` 一处比较,置 0 与新规则等价,
  且**不产生第二份实现**(PITFALLS 第 9 条)。脚本须自检:`p` 取到不可能触发的值时,
  结果必须与生产逐字节一致。

## 四、闸门(全部要过,缺一不上)
