# 预注册:玻纯跟随卡在真实手续费下能不能用(永安 / 东证)

立项日 2026-09-04,运营者:「1 手开仓是 2 元,平仓也是 2 元,你立项测一下」。
**本文在跑数之前写完并提交**,判据、闸门、结局处置事前钉死;跑完不许回来改本文,
只许在 `REPORT_FOLLOW_COST_v1` 里如实报。

## 一、为什么立项:上一次的成本口径错了

2026-09-04 我跑过一版 T+1 跟随回测,结论是「两张卡都亏」(永安 −16.0%、
东证 −12.2%)。**那一版的成本假设是错的** —— 我按引擎里通用的
「名义金额 × 0.05% 单边」算,而运营者给的真实费率是**固定 2 元/手/边**。

差多少:FG 一手名义 ≈ 20 × 953 = 19,060 元,0.05% = **9.5 元**,
是真实值的 **4.8 倍**;SA 一手 ≈ 21,340 元,0.05% = 10.7 元,**5.3 倍**。

而那一版的成本敏感性显示,这套东西**毛收益是正的、净收益是负的**:

| 单边成本 | 永安 | 东证 |
|---|---|---|
| 0 | **+3.5%** | **+19.6%** |
| 0.05%(错的那个) | −16.0% | −12.2% |

**成本正好卡在结论的翻转点上**,所以换成正确费率必须重跑,不能靠推算。
这也是本次立项的全部理由 —— 不是因为上次结论不好看。

## 二、假设

**H1(主假设)**:在真实手续费(开仓 2 元/手、平仓 2 元/手)下,
玻纯跟随卡(T+1 跟随永安 / 东证)是**正期望**的。

**H2(次假设)**:加一道**换手阈值**(手数变动小于 N 手就不动)能进一步改善 ——
上一版每天按最新持仓重算手数、天天调仓,即使费率降下来,无谓换手仍是纯损耗。

**H1 与 H2 各自独立判,不合并成一个「最优组合」去挑。**

## 三、规格(事前写死,跑完不许加格)

回测口径与卡片一字对齐,**与上一版唯一的差别是成本**:

- 每个交易日 d 收盘后拿到席位持仓 → 按 `|FG净| : |SA净|` 定两腿比例;
- 仓位强度 = 当日合计 `|净持仓|` / **截至当日**的近两年最大(PIT,封顶 1.0);
- 预算 = 50 万 × 35% × 强度,取整用 `_fit_within_budget`(宁少不多);
- 只在**对冲态**(FG 与 SA 净方向相反)持仓,同向日空仓;
- **d+1 开盘成交**,持到 d+2 开盘换成新方案(DEC-090);
- **成本 = Σ|手数变动| × 2 元**。加仓是开仓、减仓是平仓,单边都是 2 元,
  所以不必区分方向;
- 持仓口径 `net_off`(可见持仓,不含回榜推断)。

**H2 的阈值格子**:`N ∈ {1, 2, 3, 5}` 手 —— **就这 4 格**。
代表格**事前指定 N=2**,主数字报它;不许跑完挑最好的那格来报。

## 四、闸门(全部要过,缺一不上)

| | 闸门 | 判据 |
|---|---|---|
| **G1** | **席位池安慰剂(核心)** | 把**每一个**在样本内出现过 FG-SA 对冲态、且有仓天数 ≥ 200 的席位,各跑一次同一套跟随回测,得到累计收益的分布。**永安与东证各自必须落在该分布的前 25%**。这一关问的不是「它赚不赚」,而是「随便挑一家来跟是不是也这样」——上一次 `SA_RETAIL4` 就是死在这一关上 |
| **G2** | **逐年** | 正收益年份 **≥ 4/7**(2020 半年计入) |
| **G3** | **后半不塌** | 样本前后对半,**后半**累计 ≥ 0 |
| **G4** | **成本翻倍** | 开平各 **4 元/手**下仍为正 |
| **G5** | **样本不稀疏** | 有仓天数 ≥ **400**(约占全样本 26%)。对冲态那道门本就挡掉六成日子,再少就没得谈 |
| **G6** | **回撤** | 最大回撤 **≤ 35%**(= 卡片自己的保证金上限;跌穿这个数意味着按卡片下单会爆保证金) |

**H2 单独判**:阈值版必须在 4 格里 **≥3 格**优于 N=0(不设阈值),
且代表格 N=2 的四项(累计/夏普/回撤/有仓天数)不劣化。只有 1~2 格好 = 挑峰值,判否。

## 五、三种结局,各自怎么处置(事前写死)

- **H1 全过** → 写 `REPORT_FOLLOW_COST_v1`,交运营者拍板。上线动作**只有一个**:
  把卡片 `note` 里「展示不是下单指令」那句改写成如实的验收结论,并把成本口径
  写进卡片。**手数算法一个字不动。**
- **H1 全过 + H2 也过** → 额外把换手阈值加进 `follow_plan_payload`,
  卡片上显示「今日无需调整」而不是 ±1 手。
- **H1 任一关不过** → **不上**,卡片维持「展示不是下单指令」的现状。
  报告写明挂在哪一关、差多少,进 `INDEX` 待拍板区。
- **G1 不过** → **关账**,进 `INDEX` 的「已测否 · 别重走」,并明确记录:
  这两家不特别,跟谁都一样。

## 六、明确不做
