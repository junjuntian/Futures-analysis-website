# 验收:只为玻璃与纯碱重选散户反向名单 —— **闸门不过,运营者知情破例上线**

对应预注册 `PLAN_RETAIL_RESELECT_v1.md`(v1.1)。
脚本 `research/run_retail_reselect.py`。
提交顺序:`5c6bc21`(v1.0)→ `9f358e2`(v1.1 放开逐品种,仍未跑数)→ 脚本 → 本文。

## 结论

**G1 与 G2 都不过 → 按预注册第五节本应关账。运营者看过数字后拍板照改,属知情破例。**

| 闸门 | 结果 | |
|---|---|---|
| **G1 样本外胜出(核心)** | 玻璃 +0.8pp、**纯碱 −8.8pp**,纯碱夏普 0.74 → 0.35 | **✗** |
| **G2 安慰剂(两品种都要过)** | 玻璃强于 **66%** 的随机三家、纯碱 **36%**(需 ≥90%) | **✗** |
| G3 逐年(样本外) | 玻璃 2/2、纯碱 1/2 | ✗ |
| G4 选人窗口稳健 | 三个窗口选出的人重合 3/3、3/3、3/3、2/3 | ✓ |

## 一、运营者的两个预测:一个准,一个被否

**① 「中信建投应该是必然入选」—— 准。**

用 2021~2024 窗口重选,它在**两个品种上都排第 2 且三条判据全过**:

| 中信建投 | alpha 百分位 | 净多占比 | 日均持仓 | 合格 |
|---|---|---|---|---|
| 玻璃 | **99.2%** | 65.0% | 7,979 | ✓ |
| 纯碱 | **98.2%** | 54.6% | 7,214 | ✓ |

立项当天我用**2021 年前**窗口算过它是 58%/36%(择时偏好的那一半),
**换到 2021~2024 窗口就变成 99%/98%** —— 它确实是 2021 年之后才变成反向指标的,
运营者的观察成立。

顺带印证他另外两个观察:**东方财富在纯碱上被淘汰**(净多占比 49.4% < 50%、上榜率 74.4%),
**平安在两个品种都掉出前 3**。

**② 「跨品种固定有问题,席位有品种偏好」—— 选人窗口内成立,样本外不成立。**

选人窗口内的偏好是真的(平安 2021 前 玻璃 alpha 22% vs 纯碱 87%)。
但 H2 对拍显示,**逐品种选并没有换来样本外的好处**:

| 样本外 2025-01 起 | 玻璃 | 纯碱 |
|---|---|---|
| 现行三家 | −5.1% / −0.19 | **+15.4% / 0.74** |
| H1 逐品种 | −4.3% / −0.16 | +6.6% / 0.35 |
| **H2 玻纯共用** | **−2.8% / −0.07** | +6.6% / 0.35 |

**共用版在玻璃上反而更好。**那点品种偏好在样本外没有转化成收益。

## 二、最该记住的一条:重选赢不过定死的老名单

**用 2021~2024 数据重选出来的名单,在 2025~2026 上打不过 2021 年就定死的那三家。**

而 G4 说明规则本身是**稳定**的(三个选人窗口选出的人重合 3/3、3/3、3/3、2/3)——
**它稳定地选出了一组样本外更差的人。**

这与 `REPORT_RETAIL_CROSS_v1` 的立论一致:那份名单的价值不在「选得准」,
而在**定死不更新**本身。一旦开始追着最新数据重选,就回到了挑人过拟合。

## 三、上线的是运营者指定的名单,不是本次选出来的

运营者未采用 H1 选出的组合,而是**在合格池内自行指定**:

| 品种 | 上线名单 | 本次 H1 选出的 |
|---|---|---|
| 玻璃 | **中信建投 / 平安期货 / 广发期货** | 徽商 / 中信建投 / 东方财富 |
| 纯碱 | **徽商期货 / 方正中期 / 中信建投** | 徽商 / 中信建投 / 方正中期(相同) |

**玻璃那份不是 alpha 前三**,但三家在 2021~2024 筛选里**全部合格**
(中信建投 99.2%、平安 94.4%、广发 93.6%,净多与规模三条都过)。

**代价(实测,已进 DEC-211)**:

| | 现行 | 上线名单 |
|---|---|---|
| 玻璃全样本 | +209.2% / 夏普 0.64 | **+43.1% / 0.25** |
| **纯碱全样本** | +93.1% / 0.59 | **−44.8% / −0.33 / 回撤 −57.5%** |
| 玻璃样本外 | −5.1% | −6.3% |
| 纯碱样本外 | +15.4% / 0.74 | +6.6% / 0.35 |

**运营者的理由**:「不管玻璃和纯碱收益,因为这 2 个品种本来就不过关」——
纯碱主引擎是知情破例上线的(DEC-113,t=1.49)、玻璃夏普 0.64 也谈不上稳,
**回测本身就不是可靠的目标函数**。这个理由成立与否留给读者判断,数字如上。

## 四、已知的偏袒(按预注册第七节照抄)

- **「只为两品种重选」本身就是选择**,且是运营者在看过「中信建投最近亏很多」之后提出的;
- **v1.1 放开逐品种,搜索空间翻倍**,G2 因此对两品种各做一次 —— 两次都没过;
- 样本外只有约 1 年 8 个月,而现行名单享有六年;
- 「≥3 个品种」降成「2 个品种」是我的降级,没有独立依据;
- 纯碱 6 年样本,`REPORT_STATIONARITY_v1` 判它「偏非平稳一侧」。
