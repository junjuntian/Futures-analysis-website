# 反弹候选 + 移动止盈:比半 move 择时好很多,但仍 2/4 —— 左尾没堵住,不提档位

脚本:`research/run_bounce_trail.py`(事件检测复用 `run_bounce_tier.detect_events`,只换出场)。
预注册:`PLAN_BOUNCE_TRAIL_v1.md`,判据未改一字。同一张表、同一批 1,503 个进场事件。

## 规格(回顾)

启动:自进场最大有利幅度 peak ≥ 0.2×历年 move 中位;启动后自 peak 回撤 ≥ peak×1/3 即走
(1/4、1/2 敏感性);硬止损 历年 MAE 最大;窗口止点兜底;不设时间止。

## 结果(成绩 = 占当年轨区间宽度的 %)

| 组 | 次数 | 主规格 1/3:中位 / 均值 / 胜率 / t | 1/4 | 1/2 |
|---|---|---|---|---|
| Q 合格(现行 ⚡) | 751 | +15.2% / +6.3% / 75% / 1.7 | +17.7% / +7.6% / 77% / **2.1** | +11.5% / +5.8% / 72% / 1.5 |
| **B 反弹候选** | 691 | **+11.0% / +4.7% / 72% / 1.1** | +12.1% / +4.9% / 73% / 1.2 | +7.1% / +4.1% / 69% / 0.9 |
| R 其余 | 61 | +4.0% / +1.8% / 66% / 0.2 | — | — |

对照上一份:B 半 move 择时 中位 +8.5% / 均 +0.8%;B 持到期 中位 −9.4%。
**移动止盈是明显的进步**:B 均值 +0.8% → +4.7%,胜率 59% → 72%,均持有 28 日。

| 判据 | 结果 |
|---|---|
| 中位 > 0 | ✓ |
| t > 2 | ✗(1.14) |
| 胜率 ≥ 55% | ✓ |
| 不劣于 Q 同口径 | ✗(均 +4.7 vs +6.3) |

**2/4,不过。** 敏感性三档方向一致(不是参数挑的问题)。

## 为什么 t 还是上不去:左尾

B 组出场原因:移动止盈 575 / **窗口 100** / 止损 16。那 100 次是**从没反弹到启动线**
(peak 未到 0.2×move)、也没碰到历年 MAE 最大的硬止损,一路拿到窗口止点 —— 对「持到期为负」
的反弹型模板,这正是最亏的那条路。逐年均值因此反复翻负(2015 −24.7%、2019 −34.6%、
2022 −21.3%),而中位年年为正。分品种:玻璃 34 次 +33.1%/t 2.2、苹果 +11.5%、鸡蛋 +7.5%
为正;焦煤 −1.8%、**生猪 −17.7%**(中位 +6.2% 但均值深负 —— 就是没弹起来那几笔)。

堵左尾的直觉是「没启动就给时间止」(移动止盈 + 未启动 20 日走)—— **那是第三个规格,
本报告不替它试**。上一份 20 日时间止伤的是赢家,这一份没有时间止伤的是输家,中间那档
值不值得,要新立项。

## 顺带的发现(与本实验判据无关,记下)

同一套移动止盈对 **Q 合格组**也是改善:均值 +3.8% → +6.3%、胜率 60% → 75%,1/4 档 t 2.1。
现行页面对 ⚡ 之后怎么走只给「平台位止损/卖点」,没给移动止盈 —— 这可能是比反弹档位更
值得做的事,但同样需要预注册。

LH2611−LH2705 7/27 那笔在本口径下 +51%(数据到 8/21 尚未出场)。

## 判定:不加「⚡反弹进场」档位

两次验证(半 move 择时 2/4、移动止盈 2/4),方向都对、显著性都不够、都输给合格组。
反弹型模板仍按现行做法:人看四个数,按盖楼分批法手动做。
