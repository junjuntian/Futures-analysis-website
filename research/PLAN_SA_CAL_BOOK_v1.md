# 预注册:纯碱「跨月对冲簿」—— 机构的近远月反向结构能否当跨月套利进场依据

日期:2026-08-25。运营者问(REPORT_SA_SEAT_SCAN_v1 之后):纯碱聪明钱既然靠套利
赚钱,「能不能引用这个数据,作为我套利进场的依据」。方法 = 把玻纯对冲簿
(DEC-142,已过闸)的同一套状态门平移到纯碱跨月:席位在主力与次主力净持仓
**反向**时跟他的方向持价差,同向/缺数据不在场。只产证据包不部署。

## 先说丑话(测前写死)

- **期现盲区**:只看得见期货腿。若结构是期现套保(现货/仓单腿不可见),期货侧
  跨月摆位可能不含价差信息 —— 焦煤前案(REPORT_PAIR_EXPRESS_v1 路3)阵营正套
  秩相关 +0.01 被否,就是这个原因。本轮阵营版预期同死,逐家版才是主测。
- 7 个候选(六家赚钱席位 + 阵营合计),过闸者 Bonferroni ×7 复核。
- 样本 2020-06 起 ≈6.2 年,一轮暴涨暴跌,老问题。

## 冻结口径

- 价差 = 当日主力 − 次主力(纯碱主力 1/5/9,次主力 = 主力序列下一届);
  两腿各自用**自己合约**的执行价(开盘,缺则结算)算日收益,换月日用新合约自己的
  前一日价(DEC-096/main_series 同规),价差日收益 = 主力腿 − 次主力腿。
- 状态(零参数,与 DEC-142 同构):sign(席位在主力净持仓) × sign(在次主力净持仓)
  < 0 → 在场,方向 = sign(主力净)(多近空远 = 做多价差);否则不在场。
- T+1(pos.shift(2));成本 0.2%/翻转(套利指令口径,保守)。
- 候选:国泰君安/东证/永安/华泰/中信/海通(自身盈亏前六)+ 阵营合计(对照,预期死)。

## 闸门(每候选)

安慰剂(循环移位 500)p<0.05;T+2 ≥0.8×T+1;扣成本仍正;逐年披露+在场率;
过闸者 ×7 校正后如实报证据等级(≤0.05 铁闸;0.05~0.15 知情上一档;>0.15 不立)。

## 判定

任一候选站住 → 「支持采纳候选」,落地形态(展示级状态卡挂纯碱跨月组合)由运营者
拍板;全不过 → 记死因,纯碱跨月套利维持现有工具(价差分位/平台位/回归资格)。
