# 预注册:焦煤第二引擎换人 —— 先问「加个仓位够不够」,再问「换谁」

立项日 2026-09-06。运营者:「做下焦煤的第二引擎,**换掉华泰,翻向太频繁,回撤太多**,
也用 **200 日缩仓**的玻璃这个条件。**看看还有哪些席位适合**」。
**本文在写跑数脚本之前写完并提交**;跑完不许回来改本文,
只许在 `REPORT_JM_FOLLOW2_v1` 里如实报。

## 一、先把约束说清楚:焦煤只有 3 年数据

**大商所席位数据起点 2023-08-11**(`replay_start`,硬限制),到 2026-09-04
只有约 **3 年、720 个交易日**;样本里有 **43 家**席位达到 400 行以上。

**3 年 × 43 家 = 选择偏差的温床。** `SA_SEAT_SCAN` 演示过:104 家里挑夏普最高的,
能挑出 1.96 的纯噪音。**所以本项目从设计上就分成两层,不许混用**(见第三节)。

现役:**华泰期货**,满仓跟随,+150.0% / 夏普 0.97 / 回撤 **−32.7%** / **69 次翻转**
(约每月两次)。运营者的两条抱怨都指向这两个数。

## 二、要回答的问题,按顺序

**Q1(先问这个)——「加个仓位是不是就够了」。**
运营者抱怨的两条里,**回撤正是分数仓位能治的**(玻璃实测 −46.5% → −26.7%);
**翻转频率缩仓治不了**(方向不变),但分数仓位会让小仓位上的翻转**成本变小**。
所以**第一个臂是「华泰 + 200 日缩仓」,不换人**。
**如果这一步就把两条抱怨都解决了,就不该换人** —— 换人是更大的改动,要更强的证据。

**Q2 ——「换谁」。** 只有 Q1 不够时才进入。

## 三、两层结构,不许混用

| 层 | 池子 | 地位 |
|---|---|---|
| **Tier A(验收)** | **焦煤现役席位组 5 家**:东证、国泰君安、华泰、永安、东吴 | **可以据此上线**。这 5 家是**选组机制**选出来的,与跟随成绩无关,不是我挑的 |
| **Tier B(侦察)** | 全部 43 家 | **描述性,绝不判定**。任何 Tier B 的赢家**必须另立预注册复验**才能进 Tier A。报告里要照 `SA_SEAT_SCAN` 的做法做**选择偏差解剖**(在场比例、自身盈亏、翻转次数),把假象点破 |

**运营者要的「看看还有哪些席位适合」由 Tier B 回答 —— 但它给的是线索,不是结论。**

## 四、规则(照抄玻璃现行,一个旋钮不新增)

- 方向 = 该席位在**当日主力合约**上的可见净持仓(`net_off`,按合约 ffill)符号;
- 翻转 → 下一个交易日开盘成交(= **出榜后第一个可成交价**,见 DEC-238 的措辞更正);
- **没有止损、没有持有上限、不看散户、不看主引擎**;
- 仓位 = `|主力合约净持仓| ÷ 自身近 200 日、彼此隔 ≥20 日的最高 3 次均值`,封顶 1.0
  (`FOLLOW_SIZING_WIN = 200`,**沿用 DEC-234,不扫窗口**);
- 成本:翻转单边 0.05%(按当时仓位缩放)+ 分数仓位调仓 2 元/手/边(点值 60)。

## 五、闸门

| | 闸门 | 判据 |
|---|---|---|
| **G0(校准)** | **华泰满仓必须复现线上** | +150.0% / 0.97 / −32.7% / 69 翻,允许 ±0.05pp 舍入。不过 → 脚本有 bug,项目作废重来 |
| **G1(核心)** | **必须胜过等效缩仓** | 对照臂 = 同等平均敞口的固定缩仓,夏普 **≥** 它。沿用 DEC-224 |
| **G2** | **两个半样本同向** | 切 2023–2024 / 2025–2026,夏普两半都 **> 0** |
| **G_R(换人闸门,运营者点名)** | **必须在他抱怨的两件事上真的更好** | 候选相对**现役华泰满仓**:①夏普 **≥ 0.97**;②回撤**不深于 −32.7%**;③**年均翻转次数更低**。三条**全部**要过 —— 他说的就是「翻向太频繁、回撤太多」 |
| **G4** | **组合要有增益** | 与焦煤主引擎 50/50 的夏普 **> 主引擎单跑**(现役华泰做到 1.82) |
| **G5** | **不靠跳空** | 换 T+1 收盘成交重跑,夏普仍 **> 0**(方法见 DEC-238) |
| **G6(安慰剂 + 多重比较)** | **不是 5 选 1 的运气** | 序列整体随机平移(≥60 日,1000 次)。**Tier A 有 4 个换人候选,事前写死 Bonferroni:要求 p < 0.05 / 4 = 0.0125**。华泰自己不受此校正(它不是被挑出来的,是现役) |

**主口径 = 全样本**(2023-08-11 起)。**安慰剂必做** —— 这是选人问题,不是屏蔽型改动。

## 六、结局怎么处置(事前写死)

- **Q1 就够**(华泰 + 缩仓 过 G1/G2/G4/G5,且回撤与翻转成本较满仓改善)
  → **建议只给焦煤第二引擎开 `sizing`,不换人**。这是最小改动,优先于换人;
- **有候选过 G1+G2+G_R+G4+G5+G6(含 Bonferroni)** → 写报告**交运营者拍板**换人;
  **同时报「华泰+缩仓」那一格**,让他在「换人」与「只加仓位」之间选;
- **没有候选过,但 Q1 过** → 只加仓位,不换人;
- **两者都不过** → **维持现状,关账**,并在 `INDEX` 写明「焦煤第二引擎换人已测,
  5 家里无人过闸;3 年样本 + 43 家池子,选择偏差压不住」;
- **G0 不过** → 项目作废重来;
- **Tier B 出现看着很好的席位** → **一律不上**,写进报告的「线索区」,
  注明必须另立预注册;**报告里必须同时给出它的选择偏差解剖**。

## 七、明确不做

- **不扫窗口**(200 日固定)、**不扫仓位上限**、**不扫成本**;
- **不从 Tier B 直接提名上线**(见第三节);
- **不动焦煤主引擎**(共振进场 + 机构出场,一字不碰);
- **不动玻璃/铁矿石的现役第二引擎**;
- **不动焦煤席位组本身**(换第二引擎跟谁 ≠ 换席位组);
- **不因为运营者说了「换掉华泰」就默认必须换** —— 第二节的 Q1 就是为此设的,
  数据说不该换就报不该换;
- **不拿这次结果回头改本预注册。**

## 八、已知的偏袒(报告里要照抄)

- **运营者已经给了结论方向**(「换掉华泰」)。这是**立项动机不是证据**,
  Q1/Q2 的顺序与 G_R 三条硬指标就是为了让数据能推翻他;
- **华泰是现役、且它的初筛先验来自独立旁证**(流向 IC t=2.32,见 `REPORT_JM_HUATAI_v1`),
  而 4 个换人候选**没有任何独立旁证** —— 这就是给它们加 Bonferroni 而不给华泰加的理由,
  **这个不对称是有意的,报告要写明**;
- **焦煤只有 3 年样本**,半样本各约 1.5 年,`G2` 的分辨力很弱;
  现役华泰的 note 里已写「66 段胜率仅 41%、利润集中在少数长趋势段(前 5 段占 130%)、
  2026 年主要靠 6 月一波」—— **这些毛病在任何候选身上都可能重演,而 3 年样本看不出来**;
- **`REPORT_JM_HUATAI_v1` 当年的初筛也是五选一**,现役本身就带选择偏差,
  所以「候选打不过华泰」不等于「华泰是对的」;
- 玻璃的 200 日窗口是在**14 年样本**上定的,搬到 3 年样本的焦煤上属于**移植**,
  报告要写明这一点没有被本次验证。
