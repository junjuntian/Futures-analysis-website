# 预注册:纯碱大规模减空,是回补还是转向?

立项日 2026-09-05,运营者:「立项按闸门,因为这次大规模减空,我要判断准确信号,
到底是回补,还是转向」。**本文在跑数之前写完并提交**;跑完不许回来改本文,
只许在 `REPORT_SA_COVER_TURN_v1` 里如实报。

## 一、为什么这个题目值得立项

与本仓库多数研究不同,**这题的标签是事后可判的**:一次大额减空之后,
空单到底加回去了没有,数据自己会说。所以能做**真正的判别检验**
(条件转向率 vs 基准转向率),而不是只能比收益。

已知的初步观察(未预注册,本次要重做):三家老牌席位(国泰君安/东证/永安)
大额减空之后 **+5 日只有 20% 净持仓继续上升**(无条件基准 49%),
中位数是净空反而扩大 2.3 万手 —— **看起来绝大多数是回补**。
本次要回答的是:**能不能事前或早期分辨出那少数的转向。**

## 二、定义(事前写死,跑完不许改)

**席位组**:国泰君安、东证期货、永安期货(运营者 2026-09-05 指定,称「老牌机构席位」)。
`net_off` 口径;逐日合计 `多单 − 空单`。

**事件**:某交易日净持仓单日上升 ≥ **30,000 手**(净空收缩),且事件日净持仓仍 < 0。

**标签(事后判定,窗口 20 个交易日)**:

* 记事件日为 `t`,事件前一日净持仓为 `N₀ = net[t−1]`;
* **回补** = 在 `t+1 … t+20` 内,净持仓**曾经回到 ≤ N₀**(减掉的空单加了回去);
* **转向** = 整个窗口内**始终没有回到 N₀**,**且** `net[t+20] > net[t]`;
* 两者都不满足(没回到 N₀,但期末也没高于事件日)记为 **中间态**,
  在主检验里**并入回补**(保守:不把模糊的算成转向)。

**基准转向率** = 全部事件里被标为「转向」的比例。这是所有判别力的比较对象。

## 三、假设

**H1(主假设,事前指定)**:**早期确认**能分辨 ——
事件后 **3 个交易日内净持仓没有跌回 N₀**,且这 3 日里净持仓**未创新低于事件日**,
则该事件是「转向」的概率显著高于基准。

选它当主假设的理由:它是**等 3 天看一眼**的规则,操作上可执行;
而且它不依赖任何需要挑选的连续变量门槛,自由度最小。

**H2(探索性,不作上线依据)**:同日可得的四个特征有没有判别力 ——
① 加多占比(多单增量 / 净变化);② 事件当日涨跌;
③ 事件前净持仓的历史百分位;④ 事件规模(净变化手数,按中位数二分)。

**H2 全部按探索处理**:四个一起做 Bonferroni 校正(α = 0.05/4 = 0.0125),
**即使有过关的也不上线**,只写进报告供下次立项。

## 四、闸门(H1 全部要过,缺一不上)

| | 闸门 | 判据 |
|---|---|---|
| **G1** | **判别力(核心)** | 满足 H1 条件那一组的转向率,与基准转向率的差异,**Fisher 精确检验 p < 0.05**;且**绝对提升 ≥ 15 个百分点** |
| **G2** | **样本量** | 事件总数 ≥ 40,且 H1 条件组 ≥ 15 |
| **G3** | **逐年不塌** | 有事件的年份里,H1 条件组转向率 > 基准的年份 **≥ 2/3** |
| **G4** | **门槛稳健** | 事件门槛改为 20,000 与 40,000 手时,G1 的方向与显著性**同向**(p 可放宽到 0.10,但符号不许翻) |
| **G5** | **安慰剂** | 把「转向/回补」标签随机重排 500 次,H1 条件组的转向率提升需落在**上尾 5%** 之外的概率 < 0.05 |
| **G6** | **五家版同向** | 用原五家席位组(加瑞达、华泰)重跑,G1 的**符号不许翻**。三家是运营者事后指定的,这一关查它是不是靠剔人剔出来的 |

## 五、三种结局,各自怎么处置(事前写死)

- **H1 全过** → 写 `REPORT_SA_COVER_TURN_v1` 交运营者拍板。上线动作**只有一件**:
  在纯碱页的机构流向卡上加一行**事实陈述**(如「上次大额减空 t+3 未回补,
  历史上这种情形 X% 转向」),**不产生任何进出场信号,不接引擎**。
- **G1 或 G5 不过** → **关账**,进 `INDEX`「已测否 · 别重走」,
  并记录:大额减空之后,早期确认也分不出回补与转向。
- **其余任一关不过** → **不上**,进待拍板区,写明差多少。

## 六、明确不做

- **不试第二个确认窗口**:3 个交易日就是 3 个,**不许跑完再试 2 日或 5 日**
  (这是本预注册最要紧的一句);
- **不用 H2 的任何特征去构造组合规则** —— 那是四个自由度的挑选;
- **不接引擎、不产生进出场信号**(见第五节上线动作);
- 不换席位组、不换 `net_off` 口径、不动 20 日标签窗口;
- **不拿这次结果回头改本预注册**。
