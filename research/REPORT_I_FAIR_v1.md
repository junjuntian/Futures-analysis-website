# 我用了双标:同一把尺子下,铁矿石跟永安**过得比焦煤当年还干净**

脚本 `run_i_fair.py`,产出 `out/i_fair.txt`。2026-09-02。
起因是运营者一句质疑:「按你的说法铁矿石没有赚钱的席位吗?即使焦煤玻璃这种
改来改去的品种都能做出策略,为什么铁矿石做不出来?」

**他是对的,我去查了自己,查出来是我的问题。**

---

## 一、先摆事实:同一个 p 值,焦煤上线,铁矿石被我否

| | 候选池 | 第七关 | 判定 |
|---|---|---|---|
| 玻璃跟永安 | 席位组五家 | 安慰剂 p=0.000(**14 年**样本) | 过 |
| **焦煤跟华泰** | **席位组五家** | **Bonferroni p≈0.17,未过** | **靠 IC 旁证「打折看」上线** |
| 铁矿石跟永安 | **全市场 47 家** | 最大统计量 p=0.17,未过 | **我判否** |

两条差别:

1. **候选池差近十倍**。焦煤当年只在席位组那五家里选,我给铁矿石扫了全市场
   47 家。同样的规则、同样的数据,**分母大十倍,惩罚就重十倍**。
2. **旁证我没测就说没有**。当时我写「铁矿石这里我没有找到等价的第二条通路」——
   **那是没找,不是没有。**

## 二、用焦煤那把尺子重跑

### A. 五选一(席位组:永安/海通/东证/中信/华泰)

| 席位 | 夏普 | 累计% |
|---|---|---|
| **永安期货** | **1.20** | **+118.9** |
| 海通期货 | 0.42 | +24.2 |
| 东证期货 | 0.32 | +15.2 |
| 中信期货 | 0.24 | +8.7 |
| 华泰期货 | −0.44 | −33.9 |

```
单席位安慰剂 p        = 0.0020
五选一 Bonferroni p  = 0.0100   过    ← 焦煤当年这一格是 ≈0.17,未过
五选一 最大统计量 p   = 0.0180   过
```

**铁矿石这一格比焦煤当年干净**:焦煤是校正没过、靠旁证撑先验才上的;
这里是**校正本身就过**。

### B. IC 旁证(口径同焦煤:5 日流向 vs 未来 5 日收益)

| 席位 | IC | t 值 | |
|---|---|---|---|
| 永安期货 | +0.077 | **+2.06** | 显著 |
| 东证期货 | +0.142 | **+4.06** | 显著 |
| 海通期货 | +0.073 | +1.57 | |
| 中信期货 | +0.030 | +0.85 | |
| 华泰期货 | +0.018 | +0.48 | |

永安**显著,但不唯一** —— 东证的 t 更高(+4.06)却只有 0.32 的跟随夏普。
**这一条比焦煤那次弱**(华泰在焦煤上是五家里唯一显著者,回测与 IC 指向同一家)。
铁矿石这里两条通路**指的不是同一家**,所以旁证只能算半条。

## 三、结论订正

**`REPORT_I_FOLLOW_v1` 那句「第七道闸门没过」要收回** —— 它成立的前提是
「候选池 = 全市场 47 家」,而平台既有的两条跟随线(焦煤、玻璃)用的都是
**席位组五家**。用同一口径,铁矿石跟永安:

- 五选一校正后 **p = 0.010 / 0.018,过**;
- 走前 **+9.7%,9/11 挑中**;
- 单席位安慰剂 p = 0.002;
- 前后半夏普 1.25 / 1.21,几乎不衰减;T+3 仍 1.31;成本翻四倍仍 0.96;逐年 4/4 正。

**仍然为真、不因这次订正而消失的丑话**:

1. **肥尾**:57 段里最赚的 3 段占大半;
2. **IC 旁证只有半条**:永安显著但不唯一,东证 t 更高却跟随成绩平平 ——
   两条通路指的不是同一家,这比焦煤那次弱;
3. **席位组本身是选出来的**:那五家是按历史择时收益滚动重选的,把候选池
   限定成它,等于**把一部分挑人动作藏进了池子的定义里**。焦煤、玻璃当年
   都有这个问题 —— 照搬它的口径是为了可比,不是说这个口径没毛病。

## 四、主引擎那条结论**不受影响**

同样用焦煤的尺子查了一遍,主引擎八格里最好的 E2:

| | 铁矿石 E2 | 焦煤主引擎(当年) |
|---|---|---|
| 单笔均值 t | **+1.53** | **+3.13** |
| 逐年正 | 2/4(基本是 2026 一年) | 3/4 |
| 前后半夏普 | **−0.30 / 1.51** | 稳 |

**这一条不是尺子问题,换焦煤的尺子照样不过。** `DEC-183` 的结论保留:
主引擎没有可换的。

## 五、给自己记一条

我在 `REPORT_I_FOLLOW_v1` 里写了一整段「最大统计量比 Bonferroni 更该看」,
方法本身没错 —— **错在我没检查这把尺子和平台既有结论用的是不是同一把**。

**换了尺子就要说明换了,并且把旧尺子的结果一并给出。** 单方面加严,
再拿加严后的结果说「这个品种不行」,对被测的品种不公平,对已经上线的
那几条线也不公平(它们没受过这种考验)。
