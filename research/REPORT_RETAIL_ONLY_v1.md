# 散户单路五道闸门:焦煤 4/5、生猪 1/5 —— 都不过,不采纳

脚本:`research/run_retail_gates.py`。预注册:`PLAN_RETAIL_ONLY_v1.md`,判据未改。
数据到 2026-08-18,干净口径;候选沿用各自生产开关(两者只做空)。

## 焦煤 JM:4/5,挂在门槛敏感性

| | 笔数 | 累计 | 夏普 | 回撤 | t |
|---|---|---|---|---|---|
| 现行共振 | 21 | +64.2% | 0.91 | −14.7% | +2.00 |
| 散户单路 | 27 | +94.8% | 1.04 | −18.1% | **+2.57** |

| 闸门 | 结果 |
|---|---|
| 1 逐年 | 赢 3/4,正 4/4 ✓ |
| 2 选臂 walk-forward | +94.5% vs +64.2% ✓ |
| 3 门槛 0.8 / 1.2 都赢基线 | **0.63** / 0.99 vs 0.91 ✗(0.8 档输) |
| 4 名单留二 | 去任一家仍赢,3/3 ✓ |
| 5 t>0 | +2.57 ✓ |

挂掉的那关说的是:门槛松到 0.8 它就不如现行了,优势集中在 1.0~1.2 这一小段;
曲面 0.63 / 1.04 / 0.99 **不单调**,峰恰好在 1.0。21~27 笔、三年样本上,
这种「只在一个门槛上好」的形状,按本仓一路的判据就是噪音的长相。
**不提破例**:与纯碱那次不同,纯碱挂的是「事前选不出年份」而各项指标全面强;
焦煤挂的是「对参数脆弱」,性质更差。

## 生猪 LH:1/5,明确不行

散户单路 +73.0%/1.78 vs 现行 +87.4%/2.34,逐年 1/4,名单留二 0/3。
现行生猪信号本来就是五个品种里最强的,不动。

## 参考(刚换成本信号的三个,不设闸门、不提改动)

| | 现行成本 | 散户单路 |
|---|---|---|
| 玻璃 | +218.1% / 0.65 | +10.4% / 0.15 |
| 纯碱 | +93.1% / 0.59 | +125.7% / 0.57 |
| 鸡蛋 | +48.9% / 1.23 | +28.4% / 0.57 |

玻璃鸡蛋上成本信号明显更好;纯碱两者打平(0.59 vs 0.57)。都不动。

## 判定

散户单路不采纳,五个品种一个不改。运营者 2026-08-21 的判断
「散户持仓影响因子大、机构不好跟」在三路对比里是对的(机构单路四品种全垫底),
但把散户**单独**拿来当进场信号,在闸门下没有站住;它现在的位置 —— 管出场 ——
是实测里最合适的位置。
