# 预注册:玻纯联动 v2 —— 只在"两边吃"状态持仓价差(运营者点名的那条未走之路)

日期:2026-08-24。v1(REPORT_FGSA_LINK_v1)三候选全否,边界里留了一条:仅在
两阵营**反向**的 29% 时段持仓价差。运营者拍板来测(原话:「我可以买套利合约的,
玻璃在前纯碱在后,做多价差或者做空价差。测一下,你说的」)。执行工具 = 郑商所
跨品种套利指令(SP FG-SA,单笔下单、两腿同成交、保证金对锁)——v1 里"四条腿
执行滞后敏感"的丑话对套利指令减轻,但成本假设不变(0.2%/翻转,偏保守)。

## 冻结口径(承 v1)

价差 = ret_open(FG 主力) − ret_open(SA 主力);T+1(shift(2));样本 2020-06 起;
阵营 = 各品种生产 rolling_groups + signal_series 的 net。

## 两个候选(零参数,一次写死)

- **D1 阵营对冲簿跟随**:当 sign(净FG) 与 sign(净SA) 反向 → 持价差,方向 =
  sign(净FG)(即机构多玻璃空纯碱 → 做多价差;反之做空);同向或缺数据 → 空仓。
  这是运营者"两边吃"假设的最纯表达:机构自己摆出对冲簿时,跟它的方向。
- **D2 永安对冲簿跟随**:同一规则换永安单席位的两品种净持仓(v1 里唯一有形状的
  跨品种信号源,测它的对冲簿状态是不是更纯)。

## 闸门(每候选独立;两选一,过闸者 Bonferroni ×2 复核)

1. 安慰剂:仓位序列循环移位 500 次(保留在场率与节奏),p<0.05;
2. T+2 夏普 ≥ 0.8×T+1;
3. 扣成本(0.2%/翻转)仍正;
4. 逐年披露(含 2026),在场率如实报;
5. 附:反向状态内的价差表现 vs 同向状态(机制是否真在反向态里)。

## 判定

任一候选全过 → 「支持采纳候选」,落地形态(展示级/判据级)由运营者拍板;
全不过 → 玻纯价差这条线彻底关账,pair_fgsa 背景到此为止。
