# 预注册:玻璃卸仓门 30% 复验 —— 生猪的数搬到玻璃合不合适

立项日 2026-09-06。运营者:「给玻璃单独复验,这个立项吧,**因为生猪的趋势非常简单,
玻璃震荡偏多,也有大趋势,照生猪的卸仓门 >30%,会有问题**」。
**本文在写跑数脚本之前写完并提交**;跑完不许回来改本文,
只许在 `REPORT_FG_UNLOAD_v1` 里如实报。

## 一、要解决的问题

`cost_unload_max = 0.30`(「机构本轮已卸掉超过 30% 就不追」)是**全局默认值**,
六个品种共用一个数。它的出处是 `DEC-127`,而那次**只测了生猪**:

> 扫 25%~50%(`run_lh_unload_min.py`):**曲面不单调、噪音级** ——
> 45% 只多一笔(一个点上调出来的数)…**运营者拍板 30%**。

也就是说 **30% 从来就不是一个有强证据的数,而且是在「固定 5 家、永安基本不卸」
的生猪席位结构上定的**。玻璃的席位结构、行情结构都不同。

**已经发生的后果**:玻璃主引擎 **2026 年整年空仓**,
其中 **88% 的交易日**是被这道门挡下的(9 月机构已卸掉 92%)。

**注意作用域**:玻璃只在**进场**用它(`cost_entry_frame`);焦煤的 `inst` 出场也用它。
所以本次只允许**给玻璃单独配**,不许动全局默认值。

## 二、运营者的前提要先验(不是拿来当结论用)

他的推理是「生猪趋势简单 → 卸仓一路向下;玻璃震荡偏多 → 卸仓会反复来回,
30% 这道门在震荡里天天被触发」。**这是一个可以量的断言,本次必须先量再用。**
`PITFALLS`「运营者的领域直觉也要进闸门,而且可能是反的」——这条不放宽。

**G_F(前提检验,描述性)**:量三件事,玻璃 vs 生猪各一份:

1. **卸仓序列本身**:`本轮已卸掉` 的分布(中位/四分位/超过 30% 的天数占比)、
   以及它的**均值回复程度**(卸仓涨上去之后又回落的频率);
2. **机构方向的持续性**:机构组净持仓方向连续同向的天数分布;
3. **价格的趋势性**:日收益的方差比(VR,20 日 / 5 日),`VR > 1` 偏趋势、`< 1` 偏震荡。

**这一节不作否决闸门**,但结论必须照写 —— 如果玻璃并不比生猪更震荡,
**报告第一句就得说「运营者的前提没被数据支持」**,不许含混过去。

## 三、新门槛怎么定:算出来,不许挑出来

**这是本项目最容易死的地方。** `DEC-203`(从池子里搜一个更好的席位)、
`SA_ANCHOR`(换个门槛写法救回来)都死在「扫一遍挑最好的那格」。
所以门槛**不由回测收益决定**,由分布决定:

**H_主(分位映射)**

```
P = 生猪的「本轮已卸掉」序列中,0.30 所处的分位
X = 玻璃的「本轮已卸掉」序列中,同一个分位 P 对应的值
```

即:**「生猪把门开在自己卸仓分布的第 P 名,玻璃也开在自己的第 P 名」**。
`X` 是数据算出来的,**算出来是多少就是多少,不许因为回测不好看而改分位**。

**H_次(玻璃自身的噪音带)**

```
X2 = 玻璃在「机构方向未变期间」的卸仓分布的第 75 分位
```

含义:震荡里日常来回卸的那一带算噪音,门要开在噪音之上。
**75 这个分位事前写死**,不许事后换成 70/80。

- 两条都跑,**代表格事前指定 H_主**;
- 卸仓序列口径沿用线上的 `unload_series`(含 `DEC-230` 的换组不清零),**不另造**;
- 生猪那条序列用生猪线上的席位组(固定 5 家)算,**不改生猪任何规则**。

## 四、闸门

| | 闸门 | 判据 |
|---|---|---|
| **G_A(核心)** | **放宽后多出来的单子本身赚钱** | 门槛 30% → `X` 之后**多出来的那批交易**,平均单笔收益 **> 0** 且**胜率 ≥ 现行胜率 − 10pp**。规格与 `FG_LEVEL_RECHECK` 的 G_A 一致,不另立标准 |
| **G_B(变量本身有没有信息)** | **卸仓比例与收益单调** | 把卸仓门**全开**(1.0)后的全部交易,按进场日的卸仓比例切**四分位**,要求**低卸仓组平均收益 > 高卸仓组**,且 Spearman 方向为负。不过 → 这个变量对玻璃没信息 |
| **G_C** | **两个半样本同向** | 2013–2019 与 2020–2026,「`X` − 现行」的夏普变化符号相同 |
| **G_D** | **口径不脆** | `unload_regroup_seed`(DEC-230)开/关两种口径下,G_A 的结论不许翻 |
| **G_E** | **别的品种一字不动** | 生猪/纯碱/鸡蛋/焦煤/铁矿石的回测数字逐字不变(**焦煤尤其要看** —— 它的 `inst` 出场也读这个键) |

**不做安慰剂。** 卸仓门是**屏蔽型**改动,随机平移之后它照样在屏蔽,
置换分布测不到东西(`DEC-217`)。这就是为什么 G_A/G_B 必须设在机制上。

**主口径 = 全样本**(玻璃 2013-01 起);**另报 2026 年单独一栏**(运营者能对上盘面的那一年)。

## 五、结局怎么处置(事前写死)

- **G_A + G_B + G_C 全过** → 建议**给玻璃单独配 `cost_unload_max = X`**
  (写进 FG 的品种配置,**不动全局默认值**),`backtest` 串与页面「进场条件」文案同步,
  守卫测试钉住「只有玻璃覆盖、其余五个品种仍是 0.30」;
- **G_A 不过** → **保留 30%,关账**,`INDEX` 写明「玻璃单独复验过,门仍成立」;
- **G_B 不过** → 报告写明「**卸仓比例对玻璃没有信息**」,**但仍不改** ——
  「没信息」不等于「放宽更好」,要去掉这道门得另立项;
- **G_C 不过** → 不上,进待拍板区;
- **G_D 不过** → 不上(结论随口径翻,是噪音);
- **G_E 不过** → 停手查 bug,本项目作废重来。

## 六、明确不做

- **不扫档挑最优**(见第三节)。40%/50%/60%/70% 会在敏感性一节列出,
  **明确不作判据,不许拿它挑一档上线**;
- **不动全局默认值 0.30**,只允许给玻璃单独覆盖;
- **不动其他五个品种的任何规则**(焦煤的 `inst` 出场读同一个键,更要小心);
- **不动玻璃的其他进场条件**:成本、轮龄 ≥2、仍在加仓、**水位门 ≤60%**
  (`DEC-235` 刚刚复验并保留,本次一字不碰);
- **不动出场**(DEC-232 的散户门槛 2.0);
- **不动席位组、冻结名单、`retail_seed` / `retail_panel`**;
- **不拿这次结果回头改本预注册。**

## 七、已知的偏袒(报告里要照抄)

- **立项动机是一个已经发生的负面结果**(玻璃 2026 年整年空仓),
  而「空仓」本身不是错 —— 门就是用来挡的;
- **我已经看过部分答案**:2026-09-06 回答运营者时跑过「卸仓门 30% → 100%(等于关掉)」,
  看到的是全样本 **86 笔 +137.0% / 0.95 / −12.3%**(现行 46 笔 +74.2% / 0.92 / −10.3%),
  近两年多 5 笔,其中 2026 年 2 笔(+0.52% / +4.99%)。**这些是事后知情**,
  所以第四节的主判据放在「多出来的单子本身赚不赚钱」上,汇总只作背景;
- **上一个项目(`FG_LEVEL_RECHECK`)刚刚因为同一类陷阱被否**:
  全样本 +183%/1.05 看着该改,拆到单笔是三笔赢家撑的。**本次极可能是同一形态**,
  报告里必须先做那三项拆解(中位数、胜率、去掉前三大赢家)再下结论;
- **`X` 依赖生猪的分布**,而生猪的席位组是固定 5 家、永安基本不卸,
  分布本身是被压窄的 —— 这会让 `P` 偏高、`X` 偏大。**这一点对本假设有利**,必须写明;
- 玻璃现行 46 笔里已叠了 DEC-224/228/230/231/232 五项近日改动,
  交互不止卸仓门这一处,**不许把差异全记在它头上**;
- 2026 年那一栏只有 2 笔,**样本极小**,不能当依据,只能当「对得上盘面」的说明。
