# 机构持仓成本能不能当进场判据 —— 第一轮:**不能，至少这三条不能**

脚本:`research/run_inst_cost.py`。数据到 2026-08-18。

## 起因

运营者 2026-08-21 指出现行方案 C 的方向错了:

> 核心策略是跟随聪明钱，如何能获得收益的本质在于，首先方向和机构一致，如果和机构
> 反向，那就需要机构出货出的差不多了，才能和机构反向。我的数据库里面有机构持仓
> 成本，我的成本跟机构差不多，或者优于机构，才是更好的入场点。散户只能当做参考
> ……只能做辅助判断入场时机，而不是真正的入场时机。

翻成可回测的四条:

1. 方向以**机构净持仓方向**为准，同向才进；
2. 要反向，得等**机构出货出得差不多**（净持仓从峰值回落到某个比例以下）；
3. **入场价不劣于机构推算成本**；
4. 散户降级为辅助择时，不再是扳机。

这确实指向一个现行引擎完全没用到的维度 —— `hog_money.py` 里一个 `cost` 字都没有，
而 `DEC-052`/`DEC-084` 早写着「现行规则已达该信息集上限，空间在**新信息维度**」。

## 两条必须先说明的限制

**① 前视陷阱,已排除。** `reboard_inferred` 那些行是**用回榜日的增减倒推**出来的，
对被填的那几天是未来数据（`fix-sanhe-fabricated-changes.sql` 里有精确例子:
04-17 的持仓 215 = 04-18 的 824 − 609）。本轮一律排除，排掉的行数:
FG 128,097 / SA 80,054 / JD 7,562 / JM 2,987 / LH 2,520。
**成本一旦进信号，这就是活的前视源**，任何后续工作都必须继续排除。

**② 我们拿到的是推算成本，不是成交均价。** 交易所不公布成交明细。
「优于机构成本」是跟一个带误差的估计在比。

## 结果

### A 覆盖率 —— 郑商所够用，大商所不够

| 品种 | 有机构净持仓的天 | 占比 | 成本算得出 |
|---|---|---|---|
| 玻璃 FG | 3,150 | 95% | 100% |
| 纯碱 SA | 1,445 | 89% | 100% |
| 生猪 LH | 452 | 33% | 100% |
| 鸡蛋 JD | 494 | 16% | 100% |
| 焦煤 JM | 414 | 13% | 100% |

有仓的日子成本都算得出来（覆盖手数中位 100%）。但大商所三个品种只有 13~33% 的
交易日这 5 家在主力合约上有净持仓 —— **规则大部分日子无法判定**。

### B 规则 1（跟随机构净持仓方向）—— 只在玻璃上成立

单按机构净持仓方向持有，不加任何其他条件:

| 品种 | 5 日 | 10 日 | 20 日 |
|---|---|---|---|
| 玻璃 FG | +0.14% (t=2.00) | +0.34% (t=3.40) | **+0.78% (t=5.69)** |
| 纯碱 SA | +0.24% | +0.19% | −0.32% |
| 生猪 LH | +0.16% | +0.25% | +0.27% (t=0.79) |
| 鸡蛋 JD | −0.10% | −0.19% | −0.09% |
| 焦煤 JM | −0.37% | −0.77% | −0.53% |

**t 全部基于重叠样本，系统性高估，只能看符号与量级。**
玻璃单调变强且量级最大；纯碱短期正、20 日翻负；生猪弱正不显著；
**鸡蛋与焦煤为负** —— 在这两个品种上，机构净持仓方向是个反向指标。

这条不是普适规律，是玻璃这一个品种在这段样本上的性质。

### C 规则 3（成本不劣于机构）—— 原始数据指向**相反**方向

`edge = side × (机构成本 − 入场价) / σ`。edge 高 = 我的成本比机构好 = **机构正浮亏**。
按 edge 五等分，看顺机构方向的后续收益:

| 品种 | Q1（机构浮盈） | … | Q5（机构浮亏最深 / 我成本最优） |
|---|---|---|---|
| 玻璃 FG (5日) | **+0.91%** | | **−0.38%** |
| 纯碱 SA (20日) | +0.79% | | **−2.42%** |
| 焦煤 JM (20日) | +1.00% | | **−3.38%** |
| 鸡蛋 JD (5日) | +0.33% | | −1.07% |
| 生猪 LH (5日) | +0.60% | | −0.17% |

**五个品种口径一致:我的成本相对机构越优，后续收益越差。** 与规则 3 相反。

符号核对过:机构做多、成本 1000、现价 900 → edge 为正 = 我买得便宜 = 他浮亏。✓

### D 但 C 是动量的伪装 —— 控制之后什么都不剩

`edge` 与近期价格走势机械相关（相关系数 LH −0.57 / FG −0.64 / SA −0.42 /
JD −0.18 / JM −0.63）:价格刚跌过，做多的 edge 就自动变高。

在「顺机构方向的近 20 日收益」分 3 档之内，再按 edge 分 3 档（10 日前瞻，
「高−低」价差）。对照组把 edge 换成**纯价格位置**（现价相对 60 日均价），
它不含任何机构信息:

| 品种 | edge 高−低（跌/平/涨） | 对照 高−低（跌/平/涨） |
|---|---|---|
| 玻璃 FG | +0.18 / −0.99 / −2.74 | +1.76 / +0.76 / −1.13 |
| 纯碱 SA | −2.97 / −0.15 / −0.36 | +0.16 / −2.40 / −2.55 |
| 焦煤 JM | −1.03 / −1.87 / −3.34 | +1.85 / −3.68 / **−5.64** |
| 生猪 LH | +0.94 / −3.20 / +1.43 | +0.66 / −2.53 / −0.60 |
| 鸡蛋 JD | +0.74 / −0.95 / −0.99 | −0.67 / +0.36 / +2.08 |

**符号在动量档之间、品种之间都不一致，而且对照组的效应量与它相当、有时更大**
（焦煤对照 −5.64% vs edge −3.34%）。

**结论:C 那张表里的东西，一个不含任何机构信息的纯价格变量同样能做出来。
机构成本没有多说一句话。**

## 判定

- **规则 3（成本不劣于机构）:证据不支持。** 原始数据指向相反方向，而控制动量之后
  两个方向都不成立。
- **规则 1（跟随机构净持仓方向）:只在玻璃上成立**，鸡蛋焦煤为负。不能当普适规则。
- **规则 2（等机构出货出得差不多）:本轮未测。** 它是四条里**唯一不与价格机械相关**
  的一条 —— 它约束的是机构仓位的轨迹（峰值回落比例），不是价格位置。
  下一轮该测的是它。
- **规则 4（散户降级）:未单独测。** 现行方案 C 用散户当扳机本就没有统计依据
  （DEC-086 记着三方案 t 只有 0.22~0.49），降级不需要新证据支持，
  但要有替代扳机才能动。

## 下一轮该做什么

只测规则 2，因为它是唯一还没被证伪、且不是动量伪装的部分:

- 定义「出货程度」= 机构净持仓相对**过去 N 日峰值**的回落比例（因果，无前视）；
- 看「回落比例」分档后，站到机构对面的后续收益是否单调改善；
- 同样要做动量对照 —— 仓位回落与价格下跌可能也相关，必须排掉。

**这一轮的方法论纪律要保留**:排除 `reboard_inferred`、动量对照组、
逐年稳定性、聚类去重叠、样本外切分。本轮只做到动量对照就已经否掉两条，
后面几道闸门还没用上。
