# 「机构出货」当出场信号:十个组合九个输给基准 —— 不采纳

脚本:`research/run_exit_unload.py`。数据到 2026-08-18。
基准是**修完回榜前视(DEC-108)、纯碱改要 dip(DEC-110)之后**的生产口径。

## 为什么值得跑第二次

第一次(2026-08-21 上午)跑到一半停了 —— 当时发现基准本身建立在**含前视**的口径上,
基准错了对比就没意义。那次的副产物是 DEC-108。现在引擎干净了,重跑。

**这次一开始就断言先复现生产**:五个品种的基准笔数与累计逐项对上
(生猪 18/+90.8%、玻璃 228/+69.8%、纯碱 93/+58.7%、鸡蛋 26/+34.3%、焦煤 21/+67.7%),
没有触发中止。对比作数。

## 三个变体(进场完全不动,只换出场)

- **A 现状** 反向出场(散户反向信号翻向)
- **B 只用出货** 机构卸到 X% 就走,关掉反向
- **C 两个都要** 谁先到算谁

判据**事先写死**:只看逐年 walk-forward(用之前年份选 X、应用到下一年);
参数曲面不单调就是噪音;要赢基准且逐年符号多数一致。

## 结果

| 品种 | **B** walk-forward | 基准 | 赢年份 | **C** walk-forward | 基准 | 赢年份 |
|---|---|---|---|---|---|---|
| 生猪 LH | +56.8% | +64.4% | 0/2 | +62.9% | +64.4% | 0/2 |
| 玻璃 FG | **−15.9%** | +41.6% | 5/12 | **−23.4%** | +41.6% | 6/12 |
| 纯碱 SA | +0.1% | +69.8% | 2/5 | +10.9% | +69.8% | 1/5 |
| 鸡蛋 JD | +10.6% | +38.3% | 0/2 | +20.7% | +38.3% | 0/2 |
| 焦煤 JM | **+91.9%** | +53.2% | 1/2 | +48.5% | +53.2% | 0/2 |

**十个组合里九个输给基准**,玻璃两个变体还把正收益打成负的。

参数曲面同样不支持:玻璃 B 是 +24.3 / −28.3 / −35.1 / +74.5 / +19.6 / +8.8,
纯碱 B 是 −41.9 / +1.3 / +55.9 / +26.6 / +8.5 / −24.8 —— 完全不单调。
按事先写死的判据,**没有单调结构就是噪音**,那个峰值换段数据就不在了。

## 唯一「赢」的那个,不算

焦煤 B walk-forward +91.9% vs 基准 +53.2%,而且它的参数曲面**是单调的**
(+144.0 / +125.4 / +112.3 / +88.2 / +90.4 / +60.8,越早走越好) ——
五个品种里唯一有结构的一个。

但按事先写死的判据它仍然不过:

- **只有 2 个 walk-forward 年份,赢 1/2** —— 不是「多数一致」;
- **全部贡献来自 2025 一年**(+91.1% vs 基准 +47.8%),2026 是 +0.5% vs +3.6%,输;
- 基准 21 笔、变体 26 笔,**样本本来就撑不起结论**。

**我不放宽这条线。** 放宽就等于让数据自己定标准 —— 这个项目里六轮系统性寻优
(含 645 格出场搜索)全部返负结果,靠的正是不放宽。
如果哪天有人回头再看这条线索,焦煤是唯一值得看的入口,但得先有更多年份。

## 判定:不改引擎

「机构出货」作为出场信号,在五个品种上都没有赢过现有的「散户反向」。
这与 `research/PITFALLS.md` 第 5 节记的历史一致 —— 出场那块已经被搜过一轮,
换个变量再搜一次,结论没变。

**至此这条线索(运营者 2026-08-21 提出的四条规则)全部走完:**

| 方向 | 判定 |
|---|---|
| 规则 1 跟随机构净持仓方向 | 只在玻璃成立,鸡蛋焦煤为负 |
| 规则 2 等机构出货再反向 | 五品种过一个(纯碱 5 日),横截面无支持 |
| 规则 3 成本不劣于机构 | 原始数据反向,控制动量后不成立 |
| 规则 4 散户降级 | 未单独测 |
| 跟随建仓(按运营者描述重测) | **机制成立**:机构每轮赚 +0.48%~+2.21%、胜率 62%~78% |
| —— 但成本优势 | **结构上拿不到**(永远晚一天),摩擦 0.46~1.21pp/轮 |
| 挑轮次 | 五个判据全否,样本外翻号 |
| **出货当出场** | **本报告:十个组合九个输** |

**产出不是一条新规则,是三样东西**:
①「跟随的摩擦成本 0.46~1.21pp/轮」这个此前没人算过的数;
② 页面上多了「机构已卸掉 X%」这一维(只显示不进判据);
③ **顺手挖出并修掉了 DEC-108 那条前视** —— 玻璃回测 +442% 里有 92% 是它撑的。

第 ③ 项的价值超过前两项之和,而它是做这条线索的副产物。
