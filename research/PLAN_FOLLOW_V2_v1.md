## 一、先把天花板说清楚:66~82% 的利润是结构性拿不到的

运营者问「他们自己赚钱、跟随为什么赚不到,东证择时那么强,T+1 真有这么大损害」。
查清了,答案是**有**,而且是硬限制。

**时序**(郑商所):交易日 d 日盘 15:00 结算 → **16:26 龙虎榜公布** → 当晚 21:00
夜盘开盘(= 交易日 d+1 的开盘,`PITFALLS` #8)。所以跟随者最早能在 d+1 开盘进场,
而席位是**带着仓位跨过 15:00→21:00 这段**的。

把席位自己的盈亏拆成「隔夜跳空(昨结算→今开盘)」+「开盘后(今开盘→今结算)」:

| 隔夜跳空占其总盈亏 | 永安 | 东证 |
|---|---|---|
| 全部日 | **66%** | **82%** |
| 对冲态 | 87% | **123%**(盘中为负) |
| 同向日 | 62% | 75% |

**择时越强,利润越集中在信息刚公布后的第一个跳空里,而那正是跟随者拿不到的。**
实测跟随只保住 37%(东证)/ 50%(永安)。

**因此本次立项的目标不是「追平它们」**,而是:**在只剩下的那 18~34% 里,
能不能做出一个净期望为正、回撤能接受的东西。** 这个上限写在这里,
免得跑完拿「才这么点」当失败。

**订正记录**:2026-09-04 更早我报过「东证对冲态 T+1 转负 −1.01 亿」,
那是我把跟随多滞后了一天(`shift(2)`)算出来的,**错的**;正确是 **+2.53 亿**。
本次全部按正确时序。

## 二、假设

- **H1**:**拆掉「对冲态」状态门**(同向日也跟)后,跟随策略是正期望的。
  依据:那道门(DEC-142)挡掉了这两家 82~84% 的利润;初测拆掉后
  东证 +33.1% → +266.5%、永安 −16.8% → −47.5%(未预注册,本次重跑)。
- **H2**:**换手阈值**(手数变动小于 N 手就不动)能改善。
  依据:上一轮 `FOLLOW_COST` 里东证 3/4 格优于不设阈值且单调(N=5 时 +34.5%)。
- **H3**:**降杠杆**能把回撤压回可接受区间。初测拆门后回撤 −60%(东证)/
  −90%(永安),**都远超卡片自己 35% 的保证金上限**。

**三条各自独立判,不合并成一个「最优组合」去挑。**

## 三、规格(事前写死,跑完不许加格)

口径与 `run_follow_cost.py` 一致,**三处改动**:

1. **允许同向态建仓**(两腿同方向,手数比仍按 `|FG净| : |SA净|`);
2. **预热期写死**:仓位强度分母(滚动两年最大)的历史**不足 250 个交易日时不建仓**。
   上一轮就是栽在这里 —— 样本头部强度恒为 100%,满仓 4.1 倍杠杆跑,
   把永安的回撤从 −32.2% 放大到 −53.3%(`REPORT_FOLLOW_COST_v1` 8.1);
3. 成本 **2 元/手/边**,T+1 开盘成交,PIT 强度,持仓 `net_off` —— 与上一轮相同。

**参数格子**:

- H2 阈值 `N ∈ {1, 2, 3, 5}` 手,**代表格事前指定 N=2**;
- H3 资金上限 `use ∈ {35%, 20%, 12%, 8%}`,**代表格事前指定 20%**。

**共 4+4 = 8 格,就这 8 格。** 主数字报代表格,不许跑完挑最好的那格来报。

## 四、闸门(全部要过,缺一不上)

| | 闸门 | 判据 |
|---|---|---|
| **G1** | **席位池安慰剂(核心)** | **拆掉状态门之后重排**:每个有仓 ≥200 天的席位各跑一次,永安/东证需落在累计收益分布的**前 25%**。上一轮(带门)东证前 31%、永安前 48%,双双不过;拆门后名次会变,**必须重测,不许沿用** |
| **G2** | **走前挑人** | 每年年初只用**此前**数据在池子里挑当年跟谁(判据=截至该时点累计最高),拼起来的曲线需**跑赢池子中位数**。这一关问的是「事前挑得出来吗」,`REPORT_SA_RETAIL4_v1` 的教训就是全样本排名不算数 |
| **G3** | **逐年** | 代表格正收益年份 **≥ 4/6**(剔预热后从 2021 起) |
| **G4** | **后半不塌** | 样本后半累计 ≥ 0 |
| **G5** | **回撤** | 代表格最大回撤 **≤ 35%**。这是卡片自己的保证金上限,跌穿就是爆保证金,不是「收益不好」 |
| **G6** | **集中度** | 去掉贡献最大的 **5 天**后累计仍 ≥ 0。上一轮东证 +33.1% 去掉最赚 5 天变 −21.0%,这一关就是为它设的 |
| **G7** | **成本翻倍** | 开平各 **4 元/手**下仍为正 |

**H2 / H3 各自的判据**:阈值版需 4 格里 **≥3 格**优于 N=0;
降杠杆版需在代表格 use=20% 上同时满足 G5(回撤 ≤35%)与「累计 > 0」。

## 六、明确不做

- **不改成交口径**:T+1 开盘是能拿到数据后的第一个可交易时刻,
  隔夜跳空那 66~82% **物理上拿不到**,不许用任何方式把它算进来;
- **不挑席位**:G1/G2 决定人选,不许跑完从池子里挑最好的那家上线
  (那是 DEC-203 刚死过的动作);
- **不加止损、不加择时、不动强度窗口**;
- **不因为 H1 过了就顺手把卡片改成下单指令** —— 上线动作在第五节写死了;
- **不拿这次的结果回头改本预注册**。
