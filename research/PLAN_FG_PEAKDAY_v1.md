# 预注册:「卸仓 = 0」门 —— 只在机构创本轮新高那天进场

立项日 2026-09-06。运营者:「把『卸仓=0 门』立项」。
**本文在写跑数脚本之前写完并提交**;跑完不许回来改本文,
只许在 `REPORT_FG_PEAKDAY_v1` 里如实报。

## 一、线索从哪来(以及它有多脏)

`FG_UNLOAD`(DEC-236)复验玻璃卸仓门时,把门全开后按进场日卸仓比例切四分位:

| | 卸仓区间 | 笔数 | 平均 |
|---|---|---|---|
| **Q1** | **0%~0%** | 22 | **+1.85%** |
| Q2 | 4%~40% | 21 | +0.19% |
| Q3 | 40%~60% | 21 | +0.27% |
| Q4 | 60%~95% | 22 | +0.23% |

秩相关只有 −0.032,**但 Q1 是断崖**,后三档几乎无差别;
门槛从 30% 放到 100%,夏普一路横在 0.86~0.95。
读法:**这个变量不是连续起作用的,真正的分界是「卸仓 = 0」vs「卸仓 > 0」。**

`卸仓 = 0` 在 `unload_series` 的口径下等价于:**今天的合计净持仓就是本轮的最高点**
(峰值只往上走,今天创新高 → 卸仓 = 0)。所以这道门的人话是
**「只在机构还在创本轮新高的那天进场」**。

**这条线索是事后看到的**(第七节详述)。所以本次的闸门必须能独立把它证否。

## 二、假设(事前写死)

- **H_主**:玻璃把 `cost_unload_max` 从 `0.30` 改成 **`0.0`**(只允许卸仓恰为 0 的日子进场)。
  对照 = 现行 `0.30`。**不需要改代码** —— `cost_entry_frame` 本来就是 `u > umax` 则拒。
- **H_次(跨品种一致性)**:纯碱同样改成 `0.0`,与它现行的 `0.30` 对照。
  **纯碱是本项目最接近样本外的东西** —— 不同品种、不同席位组、不同出场规则(纪律制)。
  H_次**只测量,不主张上线**;要不要给纯碱上,看结果另说。

**代表格事前指定 H_主(玻璃)。**

## 三、闸门

**注意这次的方向与前两个项目相反**:`FG_LEVEL_RECHECK` / `FG_UNLOAD` 都是**放宽**,
核心问题是「多做的单子赚不赚钱」;本次是**收紧**,核心问题变成
**「被新门挡掉的那批,是不是真的该挡」**。

| | 闸门 | 判据 |
|---|---|---|
| **G_A(核心)** | **被挡掉的确实更差** | 现行 46 笔切成两半:卸仓 = 0 的「留」组 vs 卸仓 > 0 的「挡」组。要求**留组平均单笔 > 挡组**,且**去掉两组各自最大的 2 笔赢家后方向不变**(防止被少数几笔支配 —— `FG_LEVEL_RECHECK` 就是栽在这上面) |
| **G_B(有没有增量)** | **不是 `cost_need_adding` 的复读** | 玻璃现有「机构近 5 日仍在同向加仓」。必须报**两者的重叠度**(进场日集合的 Jaccard),并且四格全跑:{老条件 开/关} × {卸仓 ≤30% / =0}。要求**「关老条件 + 卸仓=0」的夏普 ≥「开老条件 + 卸仓≤30%」(即现行)**,或**四格里 `卸仓=0` 的增量在开/关老条件时符号一致**。两条都不满足 → 它只是老条件的复读,不值得加 |
| **G_C** | **两个半样本同向** | 2013–2019 与 2020–2026,「卸仓=0 − 现行」的夏普变化符号相同。**前两个项目都死在这一条,不放宽** |
| **G_D** | **跨品种同向** | 纯碱(H_次)的夏普变化与玻璃**符号相同**。不同品种是本项目唯一近似样本外的证据 |
| **G_E** | **容差不脆** | `0` 改成 `≤2%` / `≤5%` 重跑,G_A 的结论不许翻。**这不是挑档** —— 只看结论翻不翻,上线仍用严格 0 |
| **G_F(可用性)** | **信号不能稀到没法用** | 新门下**年均成交笔数 ≥ 1**,且**近七年(2020–2026)至少 3 年有成交**。同时报「卸仓 = 0 的交易日占比」。不过 → 即便统计上好看也不上,那是一台不会开火的引擎 |

**不做安慰剂。** 屏蔽型改动,随机平移之后照样在屏蔽(`DEC-217`)。这就是 G_A~G_D 设在机制与外部一致性上的原因。

**主口径 = 全样本**(玻璃 2013-01 起、纯碱 2020-06 起);另报 2025/2026 两年单独一栏。

## 四、结局怎么处置(事前写死)

- **G_A + G_B + G_C + G_D + G_F 全过** → 建议**玻璃上线 `cost_unload_max = 0.0`**
  (逐品种覆盖,**不动全局默认值 0.30**);纯碱是否跟上另行拍板,不在本次自动上;
  上线动作:改一个键 + `backtest` 串与页面「进场条件」文案同步(要把人话写成
  **「只在机构创本轮新高那天进场」**,不许只写 0%)+ 守卫测试钉住覆盖范围;
- **G_A 不过** → **关账**,`INDEX` 写明「Q1 断崖是少数笔支配的,别再回来问」;
- **G_B 不过** → **不上**,并在 `INDEX` 写明「它是 `cost_need_adding` 的复读」;
- **G_C 或 G_D 不过** → **不上**,进待拍板区,写明差多少;
- **G_F 不过** → **不上**,写明「信号太稀,不可用」;
- **G_E 不过** → 不上(结论随容差翻,是刀刃上的噪音)。

## 五、明确不做

- **不扫容差档挑最优**(0 / 2% / 5% 只做 G_E 的稳健性,上线用严格 0);
- **不动全局默认值 0.30**;
- **不动玻璃其他进场条件**:成本、轮龄 ≥2、**水位门 ≤60%**(DEC-235 刚保留)、
  `cost_need_adding`(G_B 里的开/关只是**测量**,不是改动方案);
- **不动出场**(DEC-232 散户门槛 2.0);
- **不动席位组、冻结名单、`retail_seed` / `retail_panel`**;
- **不动其他四个品种**(生猪/鸡蛋/焦煤/铁矿石);纯碱只测不改;
- **不拿这次结果回头改本预注册。**

## 六、如果过了,还欠一件事(事前声明)

`卸仓 = 0` 是**刀刃定义**:差一手就不是 0。真上线之后,
**实盘里「今天是不是本轮新高」会受当日席位数据的掉榜与修订影响**。
报告里必须单列一节:**掉榜日怎么处理**(现行 `unload_series` 在掉榜日给 NaN,
`cost_entry_frame` 会以「机构席位掉榜,今日仓位看不清」拒单)——
即掉榜日**天然不会**被误判成新高日。这一点要在报告里用数据确认,不能靠读代码断言。

## 七、已知的偏袒(报告里要照抄)

- **最大的一条:线索是我事后看到的。** Q1 那 22 笔的 +1.85% 是 `FG_UNLOAD` 跑完之后
  从四分位表里读出来的,**不是事前预测**。所以本次的核心闸门 G_A 特意要求
  「去掉各自最大 2 笔赢家后方向不变」,G_D 特意引入纯碱作为跨品种检验;
- **Q1 只有 22 笔**,而且它们是「门全开」那一臂里的,与现行 46 笔不是同一批;
- **`卸仓 = 0` 的判定受 `DEC-230`(换组不清零)影响** —— 换组那天用 9 个月高位当新起点,
  会改变哪些天算 0。本次沿用线上口径(`unload_regroup_seed = True`),
  **但报告要报另一种口径下 G_A 是否成立**;
- **收紧型改动天然减少笔数**,而玻璃基线是正的(+74.2%),
  所以 `PITFALLS`「负基线上减少交易都会变好」不直接适用 —— **但 G_F 就是为此设的**:
  笔数少到不能用,统计再好也不上;
- 玻璃现行 46 笔里已叠了 DEC-224/228/230/231/232 五项近日改动,交互不止这一处。
