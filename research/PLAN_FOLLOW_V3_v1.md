# 预注册:玻纯跟随卡 V3 —— 把资金上限定在 12%,东证能不能过全部闸门

立项日 2026-09-04,运营者在 `REPORT_FOLLOW_V2_v1` 第八节的三选项里选了
「① 按你说的 12% 试一试」,并明确「② 华泰不测、③ 换手阈值不动」。
**本文在跑数之前写完并提交**;跑完不许回来改本文。

## 一、先认下本次最大的问题:12% 是事后选的

V2 的代表格是 20%,东证在那一格挂在 G5(回撤 −38.5% vs 门槛 35%)。
我**看到 V2 的四档网格之后**才提出 12%(那一档 +81.5% / 回撤 −25%)。
**这就是「网格内挑格子」**,是 `REPORT_SA_RETAIL4_v1`(DEC-203)死过的动作。

**但这一次有一个实质区别,写清楚供事后复查:**

| use | 累计 | 回撤 |
|---|---|---|
| 35% | +266.4% | −60% |
| 20% | +178.1% | −38.5% |
| 12% | +81.5% | −25% |
| 8% | +53.5% | −18% |

**四档在两个指标上都严格单调。** 杠杆缩放是**机械的**:名义敞口按比例缩,
收益与回撤同步缩,中间不存在「某一格恰好赚到了噪音」的自由度。
所以选 12% 的性质是**在单调权衡曲线上挑一个风险点**,
不同于在信号规则里挑一格 —— 后者才是过拟合的典型形态。

**即便如此,证据等级最高只到「知情上」**,而且本次**闸门必须比 V2 更严**(见第四节 G0)。

## 二、假设

**H1**:资金上限定在 **12%** 时,拆掉对冲态状态门的跟随策略(东证)
通过全部闸门,可以从「展示」升级为「可下单」。

**只判东证。** 永安在 V2 已按预注册关账(2/7,G1 也不过),本次不复活;
华泰按运营者要求不测;换手阈值按运营者拍板不动(两轮结论相反,视为噪音)。

## 三、规格(事前写死,跑完不许加格)

与 V2 完全相同,**唯一改动是 `use` 代表格 20% → 12%**:

- 允许同向态建仓(拆掉 DEC-142 状态门);
- 预热期 250 个交易日,不足不建仓;
- 仓位强度 = 当日合计 |净持仓| / 截至当日的滚动两年最大,封顶 1.0(PIT);
- 预算 = 50 万 × **12%** × 强度,取整 `_fit_within_budget`(宁少不多);
- 成本 **2 元/手/边**,T+1 开盘成交,持仓 `net_off`;
- **不设换手阈值**(N=0,运营者拍板)。

**没有参数网格。** 本次只有一个配置,不存在可挑的格子。

## 四、闸门(全部要过,缺一不上)

**G0 是本次新增的,专为「12% 是事后选的」这件事设。**

| | 闸门 | 判据 |
|---|---|---|
| **G0** | **相邻档同向(新增)** | 12% 的**上下相邻两档 8% 与 20%** 也必须满足「累计 > 0」;且三档的回撤需**随 use 单调**。只有 12% 一格好 = 孤峰,判否 |
| **G1** | **席位池安慰剂(核心)** | 在 **use=12%** 下重跑 58 家池子,东证需落在累计收益分布**前 25%** |
| **G2** | **走前挑人** | 每年年初只用此前数据在池中挑当年跟谁,拼起来需**跑赢池子中位数**,**且绝对值 > 0**(V2 那次拼接是 −10.4%、只跑赢中位数就算过,**这一关本次加严**) |
| **G3** | **逐年** | 正收益年份 **≥ 4/6** |
| **G4** | **后半不塌** | 样本后半累计 ≥ 0 |
| **G5** | **回撤** | 最大回撤 **≤ 35%**(卡片自己的保证金上限) |
| **G6** | **集中度** | 去掉贡献最大的 **5 天**后累计仍 ≥ 0 |
| **G7** | **成本翻倍** | 开平各 4 元/手下仍为正 |

**G2 加严是本次的另一处刻意收紧**:V2 里它靠「跑赢一个负的中位数」过关,
那不足以支撑「可下单」。要上线,事前挑人这件事本身必须能赚钱。

## 五、三种结局,各自怎么处置(事前写死)

- **全过** → 写 `REPORT_FOLLOW_V3_v1` 交运营者拍板。上线动作**只有三件**:
  ① `FOLLOW_PLAN["use"]` 从 0.35 改成 **0.12**;
  ② 卡片 `note` 改写成验收结论,标明**只对东证成立、永安已关账**;
  ③ 卡头「上限」显示改为 12%。
  **手数比例算法、强度算法、状态门一个字不动**(状态门 V2 已改,本次不再动)。
- **G0 或 G1 不过** → **关账**,进 `INDEX`「已测否 · 别重走」,
  并记录:12% 那一格是网格里的运气,不是风险点选得好。
- **其余任一关不过** → **不上**,维持现状(卡片继续写「展示不是下单指令」),
  进 `INDEX` 待拍板区,写明差多少。

  这一条是本次预注册最要紧的一句;
