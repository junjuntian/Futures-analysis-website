# 预注册:给成本进场加一道「进场位置」过滤(纯碱 / 玻璃)

立项日 2026-09-05,运营者:「立项测测吧,不然进去就大亏,顶不住,
比如持仓量增减、或价格在区间中的位置。散户反向其实是重要参考,不能随便否掉」。
**本文在跑数之前写完并提交**;跑完不许回来改本文,
只许在 `REPORT_SA_ENTRY_FILTER_v1` 里如实报。

## 一、先修正上一份的措辞

`REPORT_SA_ENTRY_RESONATE_v1` 否掉的是**「散户 rz 同号 + 强度」这一种接法**,
**不是「散户反向」这个维度**。该维度现役且验收过的用法是**出场**
(`REPORT_COST_GATES_v1` 过闸时配的就是「散户只管出场」),
跨品种反向指标本身有六年样本外(`REPORT_RETAIL_CROSS_v1`)。
本次把散户以**另一种形态**(水平而非变化)重新纳入候选,见 C。

## 二、动机是可量化的,不是事后找的

运营者的观察:09-03 在低点做空,进场即大亏。实测(纯碱,成本进场信号日):

| 区间位置(0=区间最低,1=最高) | 做空信号日中位 | **09-03 实测** |
|---|---|---|
| 近 5 日 | 0.64 | **0.31** |
| 近 10 日 | 0.66 | **0.31** |
| 近 20 日 | 0.58 | — |

**做空信号日通常落在区间偏上(0.58~0.66),而 09-03 只有 0.31** ——
它属于这条规则里位置最差的一档。**「别在区间下沿做空」因此是有先验的假设,
不是为这一笔量身定做的规则。**

## 三、三个候选(事前写死,跑完不许加)

统一形式:在原成本进场条件之外**再加一个门**,不满足就不进场。出场一字不动。

**A(主假设,事前指定)—— 进场位置**
`pos_N = (结算价 − 近 N 日最低) / (近 N 日最高 − 近 N 日最低)`,`N = 10` 固定。
* 做空要求 `pos_10 ≥ q`;做多要求 `pos_10 ≤ 1 − q`。
* `q ∈ {0.4, 0.5, 0.6}` —— **就这 3 格**;**代表格事前指定 `q = 0.5`**。

**B(次)—— 持仓量方向**
`dOI` = 全品种持仓量当日变化。
* **做空要求 `dOI > 0`(新资金进场,趋势确认);做多要求 `dOI > 0`。**
  方向事前写死为「都要求增仓」,理由:减仓上涨/下跌是存量博弈,延续性差
  (2026-09-05 实测纯碱「减仓上涨」+10 日均值 +0.03% vs「增仓上涨」+1.53%)。
* 无参数,只有开/关两格。

**C(次)—— 散户水平(不是变化)**
`lvl = 散户三家合计净持仓` 在过去 250 日中的分位。
* 做空要求 `lvl ≥ r`(散户重仓做多 → 更好的做空时机);做多要求 `lvl ≤ 1 − r`。
* `r ∈ {0.5, 0.6, 0.7}`;**代表格事前指定 `r = 0.6`**。

**A 是主假设;B 与 C 是次要假设,一起做 Bonferroni 校正(α = 0.05/2 = 0.025)。**
**不许把 A/B/C 组合起来** —— 那是 3×3×2 的搜索空间。

## 四、闸门(A 全部要过才算成立;B/C 同标准但另加 Bonferroni)

| | 闸门 | 判据 |
|---|---|---|
| **G1** | **相邻档同向** | 3 格中 **≥2 格**的夏普与累计**都** ≥ 基线 |
| **G2** | **逐年** | 代表格 ≥ 基线的年份 **≥ 4/6**(纯碱 2021~2026;玻璃按其年份数取 4/7 比例) |
| **G3** | **笔数不塌** | 代表格进场笔数 ≥ 基线的 **60%**(比上一份的 50% 更严:上次代表格恰好卡在 49% 掉出去,说明 50% 这条线定得太松) |
| **G4** | **后半不塌** | 代表格后半累计 ≥ 0 **且** ≥ 基线后半 |
| **G5** | **安慰剂** | 把过滤条件的**日期整体随机平移** 500 次,代表格夏普提升需 **p < 0.05**(B/C 需 p < 0.025) |
| **G6** | **两品种同向** | 纯碱与玻璃的代表格提升**符号相同**。只在一个品种上成立 = 品种特异,按本仓惯例不上线 |

## 五、三种结局,各自怎么处置(事前写死)

- **A 全过** → 写 `REPORT_SA_ENTRY_FILTER_v1` 交运营者拍板。上线动作**只有一件**:
  在 `attach_cost_signal` 之后加这道位置门,**由品种配置开关控制**,
  `backtest` 串与 `notice` 同步重写。
- **A 的 G1 或 G5 不过** → A **关账**;B/C 即使过了也**只记录不上线**
  (它们是次要假设,且 Bonferroni 之后证据等级不足以单独支撑改引擎)。
- **全不过** → **关账**,进 `INDEX`「已测否 · 别重走」,
  明确记录:成本进场加位置/持仓量/散户水平三种过滤,都救不了它。

## 六、明确不做

- **不组合 A/B/C**(见第三节);
- **不扫 N**:位置窗口固定 10 日,**不许跑完再试 5 或 20**;
- **不动出场**、不改成本进场原有的三个条件;
- **不因为纯碱基线是负的就换基线** —— 纯碱现行 seed 下基线就是 −44.8%/−0.33
  (DEC-211 知情破例的后果),**比较对象就是它**,不许换回旧 seed 来让结果好看
  (旧 seed 的对照另报,只作参考不作判定);
- **不拿这次结果回头改本预注册**。

## 七、已知的偏袒(报告里要照抄)

- **立项动机仍来自 09-03 那一笔亏损**;A 的先验虽有实测支撑(做空信号日中位 0.58~0.66
  而那天 0.31),但**「去查区间位置」这个念头本身是那笔亏损引出来的**;
- 纯碱当前基线是 DEC-211 知情破例之后的 −44.8%/−0.33,**一个已经很差的基线容易被改善**
  —— G6「两品种同向」与 G5 安慰剂为此而设;
- 玻璃 14 年、纯碱 6 年,样本长度差一倍,G2 的年份门槛按比例折算已在表中写明;
- B 的方向(都要求增仓)取自 2026-09-05 的一次**未预注册**观察,
  **那次观察本身没过任何闸门**,所以 B 只作次要假设。
