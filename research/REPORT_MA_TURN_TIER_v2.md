## 结论(两句话)

1. **甲醇维持默认档 10%**。五道门过了三道(机制 ✓ / 方向一致 ✓ / 口径稳健 ✓),
   **G2 单调与 G3 样本外两道没过** —— 5%~12% 这一段的曲线是**平的**
   (+15.1 / +14.2 / +13.7 / **+14.0**),12% 比 10% 还高一点点,挑 5% 就是挑噪音;

## 一、先说尺子(v1 卡住的地方)

v1 用「价格变动 ÷ 当年轨区间宽」记分,而区间宽的 1% 分位是 **0.0**,
单笔到过 **−9700%**,均值整个失效。v2 换成**位置点数**:

```
幅度 = 方向 × (进场日位置 − 出场日位置) × 100      high = +1(做空价差),low = −1
```

选它的三条理由**写在预注册里,不是挑出来的**:门槛 X 本来就活在位置这把尺上
(`monitor.rs` 原话:「自极值回撤区间的 X%」= 「位置退 X 个百分点」);
它**有界** ±100 所以均值能看;它**不需要挑分母**,而 v1 正是卡在「区间宽取哪个区间」。

**两格自证都过**:

| | FU | MA |
|---|---|---|
| 按线上档位重算 `turn_crosses` 对库里存的 | **100.0000%** / 100.0000%(18,732 行 @5%) | **100.0000%** / 100.0000%(29,529 行 @10%) |
| 主口径单笔绝对值最大(须 ≤100) | 94.9 | 89.5 |

**这把尺的毛病(预注册里已写)**:出场日的区间通常比进场日宽,两个位置不在同一刻度上,
**系统性低估幅度**。它对所有档位一视同仁,所以**档位之间的比较不受影响,
但绝对值不能当收益读**。

### 为什么「一致性 10/12」和「不该改」能同时成立

一致性说的是**方向**:十二年里有十年,5% 那一档的中位数比别的档高一点。
G3 说的是**幅度**:高出来的那一点,全样本合计只有 **+1.4 个位置点**。

而 5%~12% 四个档的中位是 **+15.1 / +14.2 / +13.7 / +14.0** —— 这不是一条下坡,
是一条**平线上的抖动**。真正的下坡从 15% 才开始(+12.4 → +9.7 → +6.0)。
**在平段里挑最高点,挑的是噪音。**

对比燃油同一张表的头四档:**+20.5 / +17.9 / +16.3 / +10.9** —— 那是单调下坡,
每一档都比下一档高,所以它的 G2 过了、OOS 差 +4.2 点也过了。

**这正是 LH 与 FG 当年被否掉的同一个形状**(DEC-070 原话:「相邻档正负翻转、
逐年选择不稳,挑了就是过拟合」)。甲醇的翻转比它们轻,但性质一样。

## 四、顺手看见、但本次一行不改的两件事

预注册第五节写死「即便扫描顺手发现别的品种该改,也只在报告里提一句」。两条:

1. **`JM 20%` 的机制论据已经过期。** DEC-070 给焦煤定 20% 的理由是
   「位置日抖动**全场最高**(中位 6.4pp/日)」。那是 2026-08-18,当时全集里
   还没有 IH / I / SC / FU / MA。今天焦煤排**第 3**(6.73pp),
   上头是 IH 8.10、I 7.11。**这不说明 20% 错了**(它当初还有逐笔核查的证据),
   只说明**「全场最高」这句话现在不成立**,重验时不能再引它;
2. **IH(8.10pp)与 I(7.11pp)抖动排前二,却都在默认 10% 档**,
   从没测过。按 DEC-070 给焦煤的那条机制,它们恰恰是最该测深档的两个。
   **值得另立项**,本次不动。

## 五、已知的偏袒(照抄预注册)

1. **主口径系统性低估幅度**(第一节),绝对值不可当收益读;
2. **资格门的 `drift` 带跨年前视**:它拿同模板**其它年份**算(采集 SQL 已排除自己,
   `f.c1 <> s.c1`),但那些年份包含当前实例**之后**的年份。
   这是**页面本身的性质**,回放照抄它是为了忠实于页面,**不等于「当时能这么做」**;
3. **七档里挑最优**带多重比较,G3 的逐年留一压不干净;
4. **甲醇的组合宇宙比别的品种宽** —— 它没配 `main_month`(DEC-241 立的规矩),
   所以是「所有通过 `oi_rank<=6` 的月份对」,而 JM/JD/FG/SA/AP 都限了主力月。
   **这张表的结论不能直接搬给配了主力月的品种**;
5. `days_left` 数的是**工作日不是真交易日**(照抄生产),节假日多的年份会高估剩余;
6. 甲醇 2014-12 才起步,2015 年只有半年多,早年组合数远少于近年;
7. 去重用「每实例每侧只取首笔」(DEC-070 原话)。不去重的笔数一并列在表里
   (甲醇 197~237),**两者的结论方向一致**,但档位的绝对数会变。
