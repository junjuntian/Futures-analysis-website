# 机构成本进场信号:「没大规模减仓」5/5 全线成立,「成本不劣」纯碱鸡蛋强成立 —— 方向有货,闸门未走完

脚本:`research/run_cost_entry.py`。数据到 2026-08-18,DEC-108/111 干净口径。

## 起因

运营者对限价回踩实验(REPORT_LIMIT_ENTRY_v1)的反驳:回踩买不到不是执行问题,
是**信号慢了** —— 流量 z ≥ 1 是机构大规模进场的确认时刻,趋势已启动,
拿到的成本就高,后面不赚钱、回撤更大。要求做**状态信号**:

1. 机构在场(有方向的净持仓);
2. 价格不劣于机构均价(做多:价 ≤ 成本;做空:价 ≥ 空头成本);
3. 机构没有大规模减仓止损。

## 口径与两个坑

全部复用引擎(滚动 5 家组、PIT 净持仓、`unload_series`、出场四件套一字不动、
次日开盘成交);机构成本按加仓日主力结算价逐日 VWAP 重建(换组/翻向重置、
掉榜冻结)。**成本是前 20 截断数据上的研究代理量,不是交易所真值。**

- **坑 1(当场踩了)**:`unload_series` 的 `pct` 是 **0~1 小数**不是百分数,
  第一版阈值写 30/50 等于条件从未生效。教训:接别人的列先看量纲。
- **坑 2(当场修了)**:焦煤生猪的基线只做空,第一轮却让新信号双向跑 ——
  不公平。已补只做空版。

## 结果(公平口径:各品种沿用生产做多开关)

| 品种 | 基线(现行流量) | 主规格(成本+卸仓≤30%) | 变体 B(+机构还在加仓) |
|---|---|---|---|
| 玻璃 FG | +69.8% / 0.21 / −67.9% | +27.8% / 0.19 / −61.8% | **+65.2% / 0.30 / −49.9%** |
| 纯碱 SA | +64.6% / 0.36 / −61.8% | **+93.1% / 0.59 / −36.7%** | +62.1% / 0.47 / −36.7% |
| 鸡蛋 JD | +24.5% / 0.59 / −18.2% | **+48.9% / 1.23 / −8.9%** | +47.8% / 1.21 / −10.4% |
| 焦煤 JM | +67.7% / 0.91 / −14.7% | +13.7% / 0.32 / −27.6% | +12.6% / 0.31 / −25.9% |
| 生猪 LH | +90.8% / 2.34 / −4.2% | +58.5% / 1.70 / −5.0% | +43.4% / 1.40 / −6.7% |

(格式:累计 / 夏普 / 最大回撤。主规格按夏普 2/5 胜;变体 B 3/5 胜。)

## 三个跨品种一致的结构(比单点数字更重要)

1. **「机构没大规模减仓」这个条件 5/5 品种全线大幅改善**
   (对照无卸仓过滤:FG −14.7→+27.8、SA −29.5→+93.1、JD +15.5→+48.9、
   JM +11.1→+57.0、LH +31.5→+58.0,双向口径)。且 30%→50% 放宽全部变差,
   方向单调。**运营者规则 3 是整个实验里最硬的发现。**
2. **回撤全线砍掉三分之一到一半**(SA −61.8→−36.7、JD −18.2→−8.9、
   FG 变体 B −67.9→−49.9)。运营者的原始动机 ——「进场成本高导致回撤大」——
   的回撤那一半被直接验证。胜率同步上行(SA 45.9→51.4%、JD 42.3→64.7%)。
3. **品种again分家**:纯碱鸡蛋强成立;玻璃要求「还在加仓」才追平并大幅降回撤;
   焦煤生猪明确不如现行只做空流量信号 —— 而 JM 恰是散户单路最强(t=2.57)的品种,
   两个候选信号的强弱分布互补,不重叠。

## 判定:方向有货,但不够改引擎 —— 差两道闸门

按事先写死的判据,主规格 2/5 未过线;变体 B 3/5 过线但属于第二规格
(选择面 6 个组合,有选择效应)。改引擎前必须走:

- **逐年 walk-forward**(尤其纯碱 2025 那种年份还在不在);
- **敏感性**:成本重建对结算价/收盘价的选择、席位组换组日的行为、单笔 t 值;
- 与散户单路(见 2026-08-21 三路对比)的**组合问题**:两个候选改动不许同时上,
  先后顺序与归属品种要运营者拍板。

**明确不采纳的**:无卸仓过滤的纯成本版(五品种全负或垫底,
「只看成本不看机构手上还有没有货」等于专挑机构被套的时候上车)。
