# 测量:进场点落在 K 线的哪里 —— 纯碱确实在乱进,玻璃不是

运营者 2026-09-06:「重新测进场点,进场点的好坏,用最近 20-30 天的 k 线来衡量,
看看到底是不是买在高点和低点,先把这个测准。**先不要再测回撤了,没有意义。**」

**这是描述性测量,不产出收益判定,不改任何规则,因此没有预注册。**
脚本口径见本文第四节;席位组按运营者点名的四家(国泰君安/海通/东证/永安)与现行生产组对照。

## 一、尺子

对每一笔**真实成交**(`entry_px` = 次日开盘价,DEC-090 的成交口径),
算它在**同一合约**过去 N 个交易日高低区间里的位置:

```
pos_N = (成交价 − 近 N 日最低) / (近 N 日最高 − 近 N 日最低)
进场点得分 = 做空取 pos,做多取 1 − pos      (0~1,越高越好,0.5 = 等于随便进)
```

做空要卖在高位、做多要买在低位,所以两条腿统一成一个「得分」。

## 二、结果 —— 主问题的答案

| | 得分中位(20 日) | 做空 `pos20` 中位<br>(**该高**) | 做多 `pos20` 中位<br>(**该低**) | 进在最差一端<br>(<0.30) |
|---|---|---|---|---|
| **纯碱 现行生产组** | **0.46** | **0.47** | **0.59** | 30% |
| 纯碱 点名四家 | 0.49 | **0.60** | 0.61 | 35% |
| 玻璃 现行生产组 | 0.62 | 0.68 | 0.47 | 13% |
| **玻璃 点名四家** | **0.69** | **0.71** | **0.45** | 14% |

**三条结论:**

1. **纯碱确实在乱进,运营者的直觉被证实。** 得分中位 0.46,**比随机(0.50)还差**;
   做空卖在区间 47% 的位置(本该卖高)、做多买在 59% 的位置(本该买低)——
   **两条腿都反着**。三成的笔进在最差的一端。
2. **玻璃不是。** 得分 0.62,做空 0.68、做多 0.47,两条腿方向都对。
   **同一套判据在两个品种上表现完全不同** —— 纯碱的问题不是判据本身,是它在纯碱上没工作。
3. **换成点名四家,做空腿明显改善**:纯碱 0.47 → **0.60**,玻璃 0.68 → **0.71**。
   **但纯碱的做多腿仍然反着**(0.61,该低反高),四家没救回来。

## 三、这把尺子预测不了盈亏 —— 必须说清

按得分分三档,看那一笔后来实际赚没赚:

| | 差 <0.33 | 中 | 好 >0.67 |
|---|---|---|---|
| 纯碱 现行 | −1.74% / 胜 37% | +0.18% / 50% | −1.06% / 41% |
| 纯碱 四家 | **+0.86% / 62%** | −0.55% / 46% | −0.33% / 48% |
| 玻璃 现行 | +0.11% / 56% | +0.00% / 48% | −0.23% / 46% |
| 玻璃 四家 | +1.17% / 62% | −0.45% / 41% | +0.78% / 59% |

**四组里没有一组是「进得好 = 赚得多」,纯碱四家与玻璃现行两组还是反的。**

所以要分开说:

> **「进场点位置」是个**好的诊断指标**(它确实指出了纯碱在乱进),
> 但**不是好的择时指标**(拿它挑笔,挑不出更赚的)。**

这与 DEC-212 的独立结论一致 —— 那次把 `pos_10` 当进场门,安慰剂 p=0.363、
玻璃符号翻转,已关账。**两条来路不同的证据指向同一件事:位置能诊断,不能择时。**

因此本次**不据此改任何规则**。运营者已说下一步要单独测出场点,方向是对的:
纯碱的问题在这份测量里表现为「进场没有方向性」,而进场门已经试过三种(DEC-212)、
放宽过一种(DEC-213),都不成立。

## 四、运营者的「六成仓」机制:数据是支持的

运营者给的两个例子:海通在纯碱 09-03 暴涨**之前**建了两万多手净多(自身高位约三万手);
永安在玻璃以 932 均价建了九万手净多(其上限约十五万手)。量化成:

> 单席位 `|净持仓|` 达到自身近 500 日最大值的 **60%** 时,之后 5/10/20 日价格怎么走。

| | 事件数 | 5 日 | 10 日 | 20 日 |
|---|---|---|---|---|
| 纯碱 净多达六成 | 98 | +1.70% / 对 60% | +1.98% / 57% | +2.78% / 61% |
| 纯碱 净空达六成 | 162 | −1.69% / 对 65% | −2.87% / 65% | −2.40% / 60% |
| 玻璃 净多达六成 | 157 | +1.01% / 对 58% | +1.13% / 61% | +1.75% / 62% |
| 玻璃 净空达六成 | 215 | −0.60% / 对 58% | −0.74% / 57% | −0.55% / 54% |

按席位(10 日方向命中率):
纯碱 **国泰君安 68% / 永安 68%** / 东证 63% / 海通 58%;
玻璃 东证 62% / 永安 59% / 海通 59% / 国泰君安 53%。

**十二个格子全部 > 50%,最低 54%,两个品种、两个方向一致。**
这是这几轮里**唯一一个方向一致、跨品种一致**的发现。

**但严格地说,它现在还不能用**:事件在一轮建仓期内相关(去重只压掉了连续触发,
相邻轮次仍相关)、没有安慰剂、没算手续费、也没做成可回测的规则。
**要用它必须单独立项**,而且核心闸门应当是安慰剂与走前检验 —— 60% 出头的命中率
离噪音不远,`REPORT_SA_RETAIL4_v1` 与 DEC-212 都栽在「看着好、经不起随机平移」上。

## 五、口径(复核用)

- 成交价用 `entry_px`(次日开盘,DEC-090),**不是信号日结算价** —— 问的是「买在哪」,
  就得用真正买进去的那个价;
- 区间用**该笔自己的合约**的 `high_price`/`low_price`,不用主力串,避免换月跳空污染;
- 「六成仓」用**当日可见口径** `net_off`(`_pit_pair` 的 off 那条),不用反推值,
  否则是前视(`REPORT_PIT_LOOKAHEAD_v1`);
- 点名四家用生产的 `fixed_groups`;**注意它会把整段历史按同一组重算**,
  是 DEC-214 里那个 +40pp 前视的同一个机制 —— 所以第二节里「四家 vs 现行」
  的**位置**对比可信(位置不吃这个偏),**收益**对比不可信,本文也没报四家的收益。
