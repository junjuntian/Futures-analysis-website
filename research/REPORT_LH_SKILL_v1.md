# 生猪(LH)席位能力验证 Phase 0

日期:2026-08-19。运营者立项:「做生猪的聪明钱跟随策略,先筛出真正赚钱、能预测
方向的席位」。本轮只回答**能不能做、该做成什么形态**,不写策略代码。

复现:`python run_lh_skill.py`(Q1~Q5)、`python run_lh_momentum.py`(Q6)。
数据 `data/lh_price.csv.gz`、`data/lh_seat.csv.gz`(2026-08-19 从生产库导出)。

---

## 结论先行

**可以做,但不能照搬黄金那套。** 三条:

1. **信号要用「机构合计流向」,不是黄金那种逐家权重 + 共振计数。** 单家席位的
   加减仓事件预测力很弱(整体胜率 50%,只有东证期货 t≈2.8 显著);而八家合计
   净持仓的变化,控制动量之后偏相关 **t = 5.4 / 7.5 / 7.3**(5/10/20 日),
   与黄金引擎核心因子(t≈6.2)同量级。**合计比逐家强得多,这是与黄金相反的结论。**
2. **「等机构转多」这条规则没有样本可验。** 三年里机构合计净持仓**一天都没转正**
   (穿越零轴 0 次,净空 731 天 / 净多 0 天),而且 2025-Q4 起空头还在加码
   (-19,785 → -95,119)。运营者要跟的那个拐点,历史上从未发生过。
3. **运营者点名的两家,一家名副其实一家不是。** 国泰君安 13.88 亿里有 4.99 亿是
   择时;**永安期货 9.99 亿里只有 0.92 亿是择时**(91% 是「一直挂着两千手空单 ×
   市场在跌」的方向暴露)。真正择时占比最高的是**东证期货**(6.42 亿里 5.40 亿)。

## 三个结构性约束(先摆在前面)

| | 生猪 LH | 黄金 AU |
| --- | --- | --- |
| 席位数据 | **731 个交易日**(2023-08-11 起) | 4,520 天(2008 起) |
| 各合约相对主力偏离 | 平均 4~12%、**最大 49%** | 不到 1% |
| 同日跨合约多空并存的「席位×日」 | **30.6%** | 几乎没有 |

第二条是运营者主动点出的,实测比预想更严重;第三条意味着**品种汇总净持仓会把
跨期头寸净掉**。两者共同决定:一律**逐合约**处理(运营者已拍板),不能用一条
复权连续价代表整个品种,也不能跨合约相加手数。

第一条是硬伤:三年样本撑不起黄金那套「逐年留一 + 每席位 ≥30 事件」的检验强度。

## Q1 盈亏排行:alpha 还是 beta

把每家的净持仓换成「它自己的平均净持仓」这个常数再算一遍盈亏,得到的就是
「从头到尾挂着同样大小的仓不动」能赚到的钱(beta);实际盈亏减去它才是择时(alpha)。

| 席位 | 累计盈亏 | beta | **alpha** | 择时占比 |
| --- | ---: | ---: | ---: | ---: |
| 国泰君安 | 13.88 亿 | 8.89 | **4.99** | 36% |
| 永安期货 | 9.99 亿 | 9.08 | **0.92** | **9%** |
| 格林大华 | 9.79 亿 | 10.10 | **−0.31** | 负 |
| 中粮期货 | 9.22 亿 | 8.00 | 1.22 | 13% |
| 国投期货 | 7.52 亿 | 5.53 | 1.98 | 26% |
| **东证期货** | 6.42 亿 | 1.02 | **5.40** | **84%** |
| 东吴期货 | 4.84 亿 | 1.34 | 3.50 | 72% |
| 中信期货 | 2.70 亿 | 3.82 | −1.11 | 负 |

东证与东吴的平均净持仓只有 −227 / −435 手(其余几家两千手上下),**小仓位赚大钱**,
这正是择时能力的形状。格林大华、中信期货的择时是负的——它们赚的钱全靠方向,
调仓反而在亏。

> 口径:逐 (席位, 合约) 按结算价推算,`Σ(settle_t − settle_{t−1}) × net_{t−1} × 16`。
> 掉榜断档(间隔 > 5 自然日)不计——缺失是未知不是零。

## Q2/Q3 单家席位的事件预测力:弱

事件 = `|Δnet|` 进入该席位自身历史 80 分位(用自己的历史做门槛,否则大席位天天
有事件、小席位永远没有)。共 15,239 个事件。顺着事件方向做,20 日超额收益:

- 最好的**东证期货**:5/10/20 日超额 0.15/0.23/0.33%,**t = 2.81/2.96/2.85**,三个
  周期都显著——唯一一家。
- 海通期货短周期显著(t≈2.8)但 20 日掉到 1.25。
- 其余全部 t < 2。超额普遍只有 0.1~0.4%。
- **国泰君安压根没进前 12** ——它的 alpha 来自持仓规模与大方向,不来自事件择时。

逐年更难看:

| 年 | 事件数 | 均值 | 胜率 |
| --- | ---: | ---: | ---: |
| 2023 | 1,260 | 0.07% | 51.3% |
| 2024 | 3,587 | 0.09% | 50.8% |
| 2025 | 4,688 | 0.11% | 50.1% |
| 2026 | 5,704 | 0.03% | **44.7%** |

**基本是抛硬币,2026 年还跌破 50%。** 照黄金那套「给每家算权重再共振」做下去,
筛出来的多半是噪音。

## Q4 机构转过向吗:没有

八家合计净持仓的季度均值,全程净空且末段急剧加码:

```
2023-Q3  -17,585      2025-Q1  -23,427
2023-Q4  -18,695      2025-Q2  -17,840
2024-Q1  -16,725      2025-Q3  -19,785
2024-Q2  -23,287      2025-Q4  -59,804
2024-Q3  -15,831      2026-Q1  -82,132
2024-Q4   -9,842      2026-Q2  -95,119
                      2026-Q3  -84,804
```

**穿越零轴 0 次。净多 0 天 / 净空 731 天。**

这与运营者的判断一致(「目前生猪处于磨底阶段,所以机构全是做空」),但对策略的
含义要说清楚:**「等机构转多就转向」这条规则在历史数据里没有一个样本**。它可以
作为先验规则写进引擎,但**不能声称它被回测验证过**,阈值也无从标定。

## Q5 机构合计方向的预测力:强

信号 = 八家合计净持仓的 5 日变化(水平不能用,三年恒为负等于常数)。
收益取当日主力合约自己的前向收益。

| 信号分档 | fwd5 | fwd10 | **fwd20** |
| --- | ---: | ---: | ---: |
| 最空(加空最猛) | −1.42% | −2.81% | **−4.68%** |
| 偏空 | −0.70% | −1.69% | −3.47% |
| 中 | −0.39% | −0.69% | −1.71% |
| 偏多 | −0.52% | −0.77% | −1.33% |
| 最多(减空最多) | −0.06% | −0.81% | −1.78% |

相关系数 0.229 / 0.272 / 0.242,单调性良好。**但注意每一档都是负的**——三年单边
下跌,连「机构减空最多」之后 20 日也还在跌 1.78%。信号能区分**跌多跌少**,
样本内没有给出过「该做多」的时点。

## Q6 是不是动量的马甲:不是

这是决定值不值得做的一问。

- **机构 5 日调仓与过去 20 日行情的相关只有 +0.009** ——它不是追涨杀跌,是独立信息。
  (20 日调仓相关 +0.317,有跟随成分,所以**用短窗口**。)
- 预测力对比(相关系数):

  | 信号 | fwd5 | fwd10 | fwd20 |
  | --- | ---: | ---: | ---: |
  | 纯动量 past20 | +0.114 | +0.093 | +0.043 |
  | **机构 chg5** | +0.264 | +0.356 | +0.348 |
  | 机构 chg20 | +0.400 | +0.423 | +0.298 |

- **控制动量后的偏相关:t = +5.41 / +7.52 / +7.31**(N=391)。
- 双分档 fwd20 均值,同一动量档内机构信号仍有大幅区分度:

  | 过去 20 日 \ 机构 | 加空 | 中 | 减空 |
  | --- | ---: | ---: | ---: |
  | 跌 | **−8.09%** | −3.47% | **+0.30%** |
  | 平 | −4.52% | −2.52% | −2.54% |
  | 涨 | −4.58% | −1.42% | −1.97% |

**「跌 × 机构减空」是全表唯一的正收益格子。** 这是样本里最接近「做多时机」的
形态——虽然机构从未真的转成净多,但「跌了之后机构开始收空单」这个动作已经能
标出正收益。若要做多头信号,起点应该在这里,而不是等净持仓翻正。

## 对策略设计的指引

1. **主信号 = 八家(或按 alpha 重选的一组)合计净持仓的短窗口变化**,不是逐家权重。
   窗口取 5 日:20 日窗口混入了动量成分。
2. **做空侧有数据支撑,做多侧只能靠先验。** 做多的可行起点是「下跌后机构减空」
   (Q6 那个 +0.30% 的格子),不是「机构净持仓翻正」(零样本)。
3. **席位组选谁**:若按 alpha 而不是总盈亏来选,东证期货(5.40 亿/84%)、
   国泰君安(4.99 亿)、东吴期货(3.50 亿)、国投期货(1.98 亿)靠前;
   格林大华与中信期货的 alpha 为负,**入组前要再想想**。
   注意这是全样本挑选,**有过拟合风险,采纳前需要逐年留一检验**(PITFALLS 六)。
4. **逐合约出信号**(运营者已定)。合计信号按合约各算各的,还是先按品种算合计
   再落到主力合约,这一步没测,是下一轮要定的事。
5. **不要照抄黄金的止损/消退/中继那套参数**。那些是在 17 年金银样本上调出来的,
   生猪只有 3 年、且样本内只有一种市况(单边熊市)。

## 已知边界

- 样本三年,且**只包含一种市况**。任何在这上面调出来的参数都没有跨市况证据。
- Q5/Q6 用主力合约收益,N=391(主力换月处逐合约计算会丢一些点)。
- 「八家」是按总盈亏取的前八,与 Q1 结论(应按 alpha 选)不一致——这是本轮的
  探索口径,不是最终席位组。
- 本轮没做任何回测,没有收益曲线,不构成策略绩效预期。
