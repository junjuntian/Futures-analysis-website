# 预注册:分数仓位 —— 按席位水位建仓(玻璃 + 纯碱)

立项日 2026-09-06。运营者:「**『分数仓位 + 按席位水位建仓』单独立项,先做玻璃,
纯碱也要这样做,必须降低回撤**」。
**本文在写跑数脚本之前写完并提交**;跑完不许回来改本文,
只许在 `REPORT_FGSA_SIZING_v1` 里如实报。

## 一、要解决的问题

现行 `replay` 只有**满仓 / 空仓两态**。运营者要的是「跟着机构的仓位建仓,不一次性全部入场」。
`DEC-223` 已经用近似算法量过一次,结果**分化**:

| | 累计 | 夏普 | 回撤 |
|---|---|---|---|
| 玻璃 基线(全样本) | +43.1% | 0.25 | −33.2% |
| 玻璃 跟随永安 | +21.4% | **0.26** | **−15.7%** |
| 纯碱 跟随永安 | ——**只是线性缩仓** | | |

**玻璃像是有择时价值(平均仓位 30% 却保住 50% 收益),纯碱像是单纯缩仓。**
本次要回答的就是这件事,并且**把上次没算的调仓成本算进去**。

## 二、权重定义(事前写死,两个品种同一套规则)

**主假设 H1 —— 整组水位(不挑人):**

```
w = |组内合计净持仓| / 该序列近 500 个交易日的最大值      上限 1.0
仓位 = 原信号方向 × w(前一日收盘可见的 w,次日生效,与 DEC-090 一致)
```

**次假设 H2 —— 永安水位(运营者点名):** 同上,只是分子分母换成永安一家。
两个品种的席位组里都有永安。

- 窗口 500 日、`min_periods` 120,**沿用 DEC-222 已上线的「几成仓」口径,不另造**;
- **不设仓位下限**(w 小就是小,加 floor 就是加旋钮);
- **不挑人**:H1 完全不涉及选谁;H2 只用运营者点名的那一家,
  **禁止从池子里搜一个更好的席位** —— 那是 DEC-203 死在上面的动作。

## 三、调仓成本(上次没算,本次必算)

- 费率 **2 元/手/边**(运营者 2026-09-04 给的真实值,DEC-203 的教训:上一版按名义×0.05% 算错了 4.8~5.3 倍);
- 一手名义 = `结算价 × 点值`(玻璃/纯碱点值都是 **20**);
  所以**每边成本占名义的比例 = 2 / (结算价 × 20)** —— 在 1000 元一线约 **1 个基点**;
- 逐日换手 `turnover_t = |w_t·side_t − w_{t-1}·side_{t-1}|`,
  当日扣 `turnover_t × 2 / (结算价 × 20)`;
- **开平仓本身的成本照旧不重复计** —— 现行回测口径里进出场没有单独扣费,
  本次只扣**因分数仓位而多出来的调仓**,这样差分才干净。**报告里要写明这一点。**

## 四、闸门

运营者的验收词是「**必须降低回撤**」,所以回撤是硬条件;
但只降回撤没意义(把手数减半也能降),**所以核心闸门是「必须胜过等效缩仓」**。

| | 闸门 | 判据 |
|---|---|---|
| **G1(核心)** | **必须胜过等效缩仓** | 对照臂 = **固定仓位常数 c**,`c` 取该臂在持仓日的**平均 w**。分数仓位的**夏普 ≥ 该对照臂**。**不过这一条就说明它没有择时价值,想降回撤直接减手数即可,不必改引擎** |
| **G2(运营者点名)** | **回撤真的降低** | 代表格最大回撤 **≤ 基线**(数值上不更负) |
| **G3** | **夏普不塌** | 代表格夏普 **≥ 基线** —— 缩仓天然降收益,用夏普判「值不值」 |
| **G4** | **两品种同向** | 玻璃与纯碱「代表格 − 基线」的夏普变化**符号相同**。运营者要求两个品种都做,这条不放宽 |
| **G5** | **逐年** | 代表格 ≥ 基线的年份 ≥ **4/6 比例** |
| **G6** | **成本不翻盘** | 把费率**加到 4 元/手/边**(实际值的 2 倍)重跑,G1~G3 的结论**不许改变** |

**主口径 = 全样本**(玻璃 2013-01 起、纯碱 2020-06 起);**另报近两年**作参考。
上一份运营者指定了近两年,那是针对上一个项目;本次没指定,**取更严的全样本为主**。

**代表格事前指定 H1(整组水位)**;H2(永安)同表全报,但**主数字报 H1**。

## 五、结局怎么处置(事前写死)

- **G1 与 G2 都过、且 G4 同向** → 写报告交拍板。上线动作:
  给 `replay` 加**可选**的 `weight` 序列参数(不传 = 现在的行为,逐字节不变),
  由品种配置 `sizing` 开关控制,`backtest` 串与页面 `notice` 同步重写,
  加守卫测试钉死「不配的品种逐字节不变」;
- **G1 不过** → **关账**,并在 `INDEX` 写明:**按水位调仓没有择时价值,
  要降回撤请直接减手数**(那不需要改引擎,也不需要立项);
- **G2 不过** → 不上(运营者的验收词就是回撤);
- **只有一个品种过(G4 不过)** → 不上,进待拍板区,写明差多少。

## 六、明确不做

- **不扫窗口**(500 日固定)、**不扫 floor/上限**、**不扫费率**(只做 G6 的 2 倍敏感性);
- **不挑跟随席位**(见第二节);
- **不动进场、不动出场**(纯碱 DEC-218 的三条纪律、玻璃的四件套一字不动);
- **不动席位组、不动 `retail_seed`**;
- **不因为「运营者要求必须降回撤」就放宽 G1** —— 降回撤本身太容易达成,
  G1 才是判断这件事值不值得做的那一条;
- **不拿这次结果回头改本预注册。**

## 七、已知的偏袒(报告里要照抄)

- **H2(永安)是运营者点名的**,而 `DEC-223` 已经在玻璃上看到它好看 ——
  **这是事后知情**;H1(整组,不挑人)为此而设,并被指定为代表格;
- **500 日这个窗口来自 DEC-222**,而 DEC-222 的门槛(60%)是照运营者对近期盘面的描述定的;
- 纯碱近两年只有 7 笔;全样本 26 笔。**分数仓位不改变笔数,但它改变的是每一笔的权重,
  样本仍然是那 26 笔**;
- 纯碱主引擎是知情破例(DEC-113),DEC-218 的出场也才上线一天;
- **调仓成本只扣「因分数仓位多出来的那部分」**,不是全口径手续费回测。
