# 预注册:成本进场加一道散户反向确认(纯碱 / 玻璃)

立项日 2026-09-05,运营者:「纯碱进场逻辑明显有问题…进场应该多维度判断,
不光是机构加仓强度,还得看散户是否反向、反向强度高不高」。
**本文在跑数之前写完并提交**;跑完不许回来改本文,
只许在 `REPORT_SA_ENTRY_RESONATE_v1` 里如实报。

## 一、立项的直接触发:2026-09-03 那笔

纯碱 09-03 触发做空信号、09-04 开盘 1058 成交,当日就 −2.08%,夜盘到 1110。

查下来**两路信号当时是相反的**(生产库实测):

| 日期 | 旧三家散户净持仓 | 日变化 | 散户反向含义 |
|---|---|---|---|
| 09-01 | 35,790 | +18,510 | 加多 → 看跌 |
| 09-02 | 35,416 | −374 | — |
| **09-03** | **23,561** | **−11,855** | **减多 → 反向看涨** |
| 09-04 | 18,798 | −4,763 | 减多 → 反向看涨 |

**成本信号说做空,散户反向说看涨,引擎只看前者。**

现行接线(`entry_exit_signals`):`signal_source="cost"` 时
**进场只用 `cost_z`,散户那一路只管出场**(DEC-112)。
`REPORT_COST_GATES_v1` 当年过闸时,进场也没要求过散户确认。

## 二、假设

**H1(主)**:成本进场**加一道散户反向同号确认**,能改善纯碱。
具体:原进场条件之外,再要求 `sign(cost_z) == sign(rz)`
(做空需 `rz < 0` 即散户在加多;做多需 `rz > 0`)。

**H2(强度档)**:确认不只要求同号,还要求 **|rz| ≥ k**。
`k ∈ {0, 0.5, 1.0}` —— **就这 3 格**,`k=0` 即 H1。
**代表格事前指定 `k = 0.5`**,主数字报它;不许跑完挑最好的那格来报。

**H3(玻璃)**:同一改动在玻璃上是否也成立 —— **独立判**,
不与纯碱合并成「两品种平均」去凑。

## 三、口径(事前写死)

- 只改**进场**,出场四件套一字不动(散户翻向 / 止损 / 持满 / 临近交割);
- `rz` 用**当前生产的 retail_seed**(纯碱 徽商/方正中期/中信建投,
  玻璃 中信建投/平安/广发,DEC-211 刚上线);
  **同时报一份用旧三家(东方财富/平安/徽商)的结果作对照** ——
  两份名单差异巨大,不报会看不出结论对名单有多敏感;
- 其余一切不动:成本进场的三个条件、卸仓 ≤30%、次日开盘成交、PIT 口径;
- 全样本 `replay_start` 起(纯碱 2020-06、玻璃 2013-01);
- **不设预热期特例**:`rz` 本来就要 60 个交易日预热,期间自然不进场。

## 四、闸门(全部要过,缺一不上)

| | 闸门 | 判据 |
|---|---|---|
| **G1** | **相邻档同向** | `k ∈ {0, 0.5, 1.0}` 三格中 **≥2 格**的夏普与累计**都** ≥ 基线。只有一格好 = 挑峰值 |
| **G2** | **逐年** | 加确认后 ≥ 基线的年份 **≥ 4/6**(纯碱 2021~2026) |
| **G3** | **笔数不塌** | 进场笔数 ≥ 基线的 **50%**。确认是过滤器,必然减少笔数;砍掉一半以上就不是「提高质量」,是「几乎不做了」 |
| **G4** | **后半不塌** | 样本后半累计 ≥ 0 且 ≥ 基线后半 |
| **G5** | **安慰剂** | 把 `rz` 的**日期整体随机平移** 500 次(保留其自相关结构,只打乱与价格的对齐),代表格的夏普提升需 **p < 0.05** |
| **G6** | **对名单不敏感** | 用旧三家名单重跑,代表格的**符号不许翻**(仍优于各自基线)。若只在新名单下成立,说明吃的是 DEC-211 那次换人的运气 |

**玻璃(H3)独立走同一套闸门。** 纯碱过、玻璃不过时,**只上纯碱**。

## 五、三种结局,各自怎么处置(事前写死)

- **全过** → 写 `REPORT_SA_ENTRY_RESONATE_v1` 交运营者拍板。上线动作**只有一件**:
  在 `entry_exit_signals` 里给 `signal_source="cost"` 的进场加这道确认,
  **由品种配置开关控制**(只给过闸的品种打开),`backtest` 串与页面 `notice` 同步重写。
- **G1 或 G5 不过** → **关账**,进 `INDEX`「已测否 · 别重走」,
  记录:散户确认救不了成本进场。
- **其余任一关不过** → **不上**,进待拍板区,写明差多少。

## 六、明确不做

- **不扫更多阈值**:3 格就是 3 格,**不许跑完再试 k=0.3 或 0.8**;
- **不动出场**(`REPORT_COST_GATES_v1` 的闸门是连着出场一起过的,换出场作废);
- **不改成本进场本身的三个条件**;
- **不因为纯碱不过就改判据去救它** —— 纯碱主引擎本就是知情破例(DEC-113);
- **不拿这次结果回头改本预注册**。

## 七、已知的偏袒(报告里要照抄)

- **立项动机来自 2026-09-03 那一笔亏损** —— 这是**事后看到一次坏结果才提出的规则**,
  天然带「为这一笔量身定做」的风险。G2 逐年与 G5 安慰剂为此而设;
- `retail_seed` 刚在 2026-09-05 换过(DEC-211,且那次预注册的闸门没过),
  **结论可能对名单敏感** —— G6 为此而设;
- 纯碱 6 年样本、`REPORT_STATIONARITY_v1` 判「偏非平稳一侧」;
  纯碱主引擎自身 t=1.49,**基线本来就不稳**,「改善」容易是噪音上的改善;
- 加确认必然减少笔数,而**笔数一少,夏普天然容易变好** —— G3 就是防这个。
