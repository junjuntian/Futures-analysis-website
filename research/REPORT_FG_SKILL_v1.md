# 玻璃(FG)席位能力验证:结论是**不立项**

日期:2026-08-19。运营者要求「按生猪的流程做玻璃」。按同一套流程走完 Phase 0/1,
**数据不支持做这个策略**,所以停在验证阶段,没有进入回测与上线。

复现:`python run_fg_skill.py`(Phase 0+1)、`python run_fg_probe.py`(换形态再探)。
数据 `data/fg_price.csv.gz`、`data/fg_seat.csv.gz`(2026-08-19 从生产库导出)。

---

## 结论先行

玻璃的**先天条件比生猪好得多**,但**信号不成立**——两件事都要说清楚。

先天条件(全都优于生猪):

| | 玻璃 FG | 生猪 LH |
| --- | --- | --- |
| 席位样本 | **3,329 个交易日**(2012-12 起,跨牛熊) | 731 天(单一熊市) |
| 数据来源 | 纯 `czce_official` 单一来源 | 四个源并存 |
| 合约相对主力偏离 | 6.6% / 最大 25.8% | 7.1% / 最大 43.4% |
| 席位 alpha 量级 | 中信 **38.5 亿**(beta 仅 1.44) | 国泰君安 4.99 亿 |
| 逐年留一排名相关 | **中位 0.99、最低 0.88** | 中位 ~0.95、最低 0.77 |

**席位确实在赚钱,而且赚的是择时的钱**(中信 alpha 38.5 亿 / beta 1.44 —— 14 年跨牛熊,
方向暴露被自然抵消掉了)。但**"跟随他们的持仓变化"提取不出稳定的方向信息**:

1. **滚动样本外随时间衰减,最近一年反向显著。** K=5:训练截止 2016/2018/2020/2022/
   2024/2026 → t = +2.28 / +2.70 / +2.23 / +1.37 / +1.09 / **−2.77**。
   而且 corr 只有 0.05 量级,生猪是 0.4。
2. **分时期符号翻转三次。** 2013~16 **+3.22** / 2016~19 **−2.95** / 2019~22 **+6.45** /
   2022~25 +2.16 / 2025~27 −0.57。这比"被套利掉了"更糟——衰减至少是单调的,
   符号乱翻说明**全样本那个 t=+2.96 是被 2019~2022 一段单独撑起来的**。
3. **换成金银那套「单家事件」也不行。** 85 家里 |t|>2 的只有 10 家,最高 2.84,
   超额 0.1~0.2%。85 家做多重检验,随机期望就有 4~5 家过线——10 家不构成证据。
4. **挑人这一步在玻璃上不产生价值。** 同一段样本外:按 alpha 选 t=1.37、按总盈亏选
   **t=1.37(完全相同)**、按 beta 选 t=1.09。玻璃的 beta 本来就小,alpha 排序与总盈亏
   排序几乎是同一张表,生猪那个"按 alpha 选 5.22 vs 按规模选 0.11"的分野在这里不存在。

## 为什么生猪行、玻璃不行(推测,未验证)

生猪的信号强度来自一个很特殊的结构:**产业空头 vs 散户多头**分层极干净(前 8 名全净空、
后 5 名全净多,东方财富一家亏 14 亿),机构的方向判断高度一致且持续。

玻璃是成熟品种、流动性好、参与者结构复杂——大量席位同时在做 FG-SA 跨品种套利
(这正是本平台套利监控盯的组合),持仓变化里混着套利腿的调整,不等于对玻璃的方向判断。
**这是推测,没有验证过**,写在这里只是给下一个人一个起点。

## 处置

- **不上玻璃的机构资金策略。** 没有证据支持,上了就是拿一套精致的规则包装噪音。
- 研究脚本与数据保留,`lhlib` 已参数化(`load_price("FG")`),下次要重验一条命令就行。
- 玻璃在本平台已有合适的用法:**套利监控里的 FG-SA 组合**,那条路是有数据支撑的。
- 若日后仍想做,建议的方向不是调参数,而是换信号源(例如仓单、基差分位),
  因为本轮否掉的是"持仓变化携带方向信息"这个前提本身。

## 边界

- 本轮只验证了「合计流向」与「单家事件」两种形态,不能推广成"玻璃的席位数据毫无用处"。
- alpha 排行本身是可信的(14 年、逐年留一相关 0.99),被否掉的是**用持仓变化预测价格**。
