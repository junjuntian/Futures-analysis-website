


## DEC-120 反弹窗口按所选交易日显示;套利页日期选择器点击即弹(2026-08-23)

运营者两条反馈:①套利监控页的日期选择器「有时候不弹」;②选了日期之后,反弹窗口
还显示机构**最新**状态 —— 他要看的是**那天**的机构状态,拿来手动验证信号。

①日期选择器原来 `editable` 且在「可选日期列表为空」时整体禁用:点进输入框是在文字里
放光标而不是弹面板,列表没回来那一瞬又是禁用态。改成 `:editable="false"`(点击即弹)、
只在历史信号模式下禁用(那个模式不按单日看);列表没回来之前面板能开、日子不可选。

②引擎 payload 新增 `bounce_history`:逐日 {d, active, unload, side},PIT 口径(当天可见),
728 行、106 天活跃(与 REPORT_LH_SPREAD_SIGNAL_v1 一致)。前端 `pickBounceDay(history, date)`
取最后一个 d ≤ 所选日的行 —— **每一行按它自己的交易日取**(历史信号模式下各行日期不同);
早于历史起点不编数据、不拿最新的顶;周末/节假日退到前一天时把「按 X 日机构状态」写出来。
测试 +3。
