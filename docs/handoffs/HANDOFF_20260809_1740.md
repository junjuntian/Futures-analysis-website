## 2. 逐条根因与修复

### 2.1 时间滑块「没做」——其实做了，但被 echarts 静默丢弃（**通用坑，务必记住**）

`spreadCharts.ts` 里 `dataZoom` 配置早就写了，但页面上从来没出现过滑块。

根因：`frontend/src/components/SpreadChart.vue` 用的是 **echarts 按需（tree-shaken）入口** —— `import { init, use } from 'echarts/core'`，组件必须显式 `use([...])` 注册。**未注册的组件，其 option 会被静默忽略，不报错、不告警、控制台干净。** 当时只注册了 `LineChart / GridComponent / LegendComponent / MarkLineComponent / TooltipComponent`，漏了 `DataZoomComponent`，于是整段 dataZoom 配置形同不存在。

修复：在 import 和 `use([...])` 两处都补上 `DataZoomComponent`，并在文件里留了注释说明这个静默失效的机制。

**给后续接手的人**：以后在这个项目里给图表加任何新 echarts 特性（toolbox、visualMap、dataset、markArea、brush…），**先确认对应 Component 已经 `use()` 注册**。「配置写了但页面没反应」在这个代码库里的第一嫌疑永远是漏注册，而不是配置写错。

### 2.2 内置「常用」组合下架 + 收藏命名带品种名

原来 `FreeSpreadView.vue` 硬编码了 5 个预设（卷螺差 / 豆棕差 / 油粕比 / 玻璃-纯碱 / 焦煤 9-1），运营者从没要过，且和「收藏」并排显示容易被误认成已保存项。

改动：
- 删除 `Preset` 接口、`presets` 数组、`applyPreset()` 函数、模板里的 `v-for="preset in presets"` 那一段。
- 「常用」标签改成「收藏」，且 `v-if="favorites.length"` —— 没有收藏时整行只剩「自定义收藏」按钮，不再有多余文字。
- 首次进页面默认选中焦煤 09-01 的逻辑原来是靠查 `presets` 里那条预设实现的，删预设后改成 `onMounted` 里直接写：找到 JM 品种就 `changeVariety('leg1','09')` / `changeVariety('leg2','01')`，找不到就退回第一个品种。**功能没变，只是不再依赖预设表。**
- 新增 `legLabel(key)`，收藏默认名从 `jm09-jm01` 改为 `焦煤jm09-焦煤jm01`（品种名 + 小写代码 + 月份）。仅影响弹窗里的默认值，用户仍可改名；后端与已有收藏不受影响。

### 2.3 季节叠年图配色 + 底部被挡

两个独立问题被运营者合在一条里说：

**配色**：原来 `year.year === currentYear ? '#df572d' : '#cacac8'`，即除当年外全部同一个灰，十几年的曲线糊成一团，叠年图存在的意义（逐年对比）直接失效。改为 `SEASONAL_PALETTE` 12 色轮转分配给历史年份，当年仍用 `CURRENT_YEAR_COLOR`（`#df572d`）且加粗到 3.5px 独占；历史线 1.6px、opacity 0.85，`emphasis.focus: 'series'` 便于悬停聚焦。图例色块自动跟随 series 颜色，所以图例现在也能直接认年份。同时删掉了 option 上那个已经无效的 `color: [...]` 调色板数组。

**底部挡住日期**：不是图表配置的问题。`.export-actions`（PNG / SVG 两个按钮）是 `position: absolute; right: 2px; bottom: 3px`，**浮在图表右下角上面**，正好压住 x 轴最后几个日期标签；连续走势图那边还会压住新加的时间滑块。改成随文档流放在图表下方右对齐（`display:flex; justify-content:flex-end; margin-top:6px`），两张图一起解决。季节图 grid 底部同步从 40 放宽到 44。

## 3. 运营者另问：图上灰线和黄线是什么

已当面答复，同步记录（都来自 `continuousChartOption` 的 markLine，`spreadCharts.ts:15-37`）：

- **橙色横虚线** = 当前价差值（`current_value`），右端带数值标签，用于看当前处在历史什么位置。
- **灰色竖虚线** = 换段边界，即两腿合约换月那一天，提示线左右不是同一组合约、不能连着读。
- 另有一条贯穿的浅灰横线是 **零轴**。

用原始上游数据（`ajax/arbitrage_varieties.php` 的 jm 09-01 全量 3260 点）离线复算过一遍窗口过滤，**换段边界恰好 13 根、逐年一根**，位置为每年 8 月底（前腿散户截止）跳到次年 1 月中（新组合上市）：

```
2013-08-30 jm1309-jm1401 -> 2014-01-16 jm1409-jm1501
2014-08-29 jm1409-jm1501 -> 2015-01-19 jm1509-jm1601
...
2025-08-29 jm2509-jm2601 -> 2026-01-19 jm2609-jm2701
```

离线复算保留 2071 点，与生产实测 `retained_points=2069` 基本吻合（差 2 点来自本库交易日历与「交割月前月最后工作日」回退近似的差异，属已披露的近似）。

**遗留**：运营者截图里 2018 年附近那根换段线看上去比其他 12 根明显更粗更密。位置换算下来正是 `2018-08-31 -> 2019-01-16` 那一根，属同一类线，但为何渲染更粗尚未定论（怀疑是 markLine 标签或多条线叠加）。**待浏览器放大确认，未解决。**
