## 已交付内容

- 首次系统初始化接口：创建首个系统所有者、个人 Workspace、Owner membership、初始 Session。
- Cookie Session：绝对有效期 7 天、空闲有效期 4 小时、每用户最多 5 个并发 Session，超过上限撤销最旧 Session。
- Cookie 安全属性：`HttpOnly`、`SameSite=Lax`、明确 `Path=/`；开发 HTTP 环境允许 `Secure=false`；生产环境要求 HTTPS 与 `Secure=true`。
- CSRF：有副作用请求要求 CSRF token。
- 密码策略：15-128 字符，允许 Unicode/空格/密码短语，不强制组合；拒绝常见密码；使用 Argon2id。
- Argon2id：集中参数 memory=64MiB、iterations=3、parallelism=1、version=1；支持参数版本升级后的下次登录 rehash。
- 登录失败审计和限速：失败登录写 `security_events`；429 限速拒绝写 `auth.login` / `denied`。
- 权限基础：基础角色、权限摘要、非 admin 不可撤销他人 Session。
- Workspace 隔离：个人 Workspace、membership、API 当前 Workspace、PostgreSQL RLS 双层基础。
- 部署配置：API/Worker 使用 `DATABASE_URL_FILE`；API 使用 `BOOTSTRAP_TOKEN_FILE`；Compose 改为只读挂载 secrets 目录。
- Nginx：`/api/` 与 `/api-docs/` 代理到 API。
- 前端：初始化/登录/登出/Session 页面与身份状态管理。
