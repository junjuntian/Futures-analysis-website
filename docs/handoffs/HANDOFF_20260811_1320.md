## 关键决策

1. **过滤与归一化分层**：SQL 过滤只用原始列 + 纯比较（RLS 安全），归一化在 Rust
   或小结果集的展示键上。红线写在 `MEMBER_KEY` 的文档注释里，两条测试盯着。
2. **自算汇总与官方汇总必须分得清**（`variety_total_is_computed`），且只补官方缺的
   组合——郑商所不叠第二份。change 用交易所公布的逐合约增减求和，不是相邻日相减。
3. **镜像复用不放宽守卫**：把「镜像来自本次 sha」细化为「来自与本次 sha 在其输入
   路径上逐字节一致的提交」，deploy runner 用 git diff 实核。构建侧 `paths` 与
   deploy 侧 `image_paths` **两边路径集必须同步改**。
4. **性能验证必须在 `futures_runtime` + RLS 下做**（`set role` + `set_config`），
   `futures_app` 绕过 RLS，测的不是生产路径——本轮事故的教训。
