## 2026-09-02:`Failed to fetch`(DEC-175)

自由价差页报 `Failed to fetch`。**服务器是干净的** —— 宿主与容器两级 nginx 的
access log 里连一行都没有、error log 全空、同一组合手工重放 396ms 回 200。
根因是 HTTP/2 连接闲置超过 nginx 默认 `keepalive_timeout 65s` 被关掉,浏览器
复用它发请求;**GET 浏览器会自己重发,POST 不会**,所以全站只有这个查询接口露馅。
修法:只读的查询 POST 自动重发一次(收藏增删是真写入,**不重试**),
文案改中文并点明「服务器日志里不会有记录」。
