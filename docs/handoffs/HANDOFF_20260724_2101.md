## 关键决策

- 数据归属于 Workspace；MVP 每个用户只有个人 Workspace，不实现共享和邀请。
- 所有业务表必须通过 `workspace_id` 做租户隔离。
- MVP 排除规则驱动历史回测，只做统计、季节性、百分位、极值、回撤和情景计算。
- 系统时间使用 UTC 与 `TIMESTAMPTZ`；业务时区为 `Asia/Shanghai`。
- 市场数据独立保存 `trade_date` 与 `session_type`，夜盘按交易所日历归入下一交易日。
- 收盘价和结算价分别保存，分析结果必须标记 `price_basis`。
- MVP 不自动生成连续合约。
- 原始成交不可覆盖，开平配对默认 FIFO。
- 业务实体主键使用应用层 UUIDv7；高频时间序列和明细表使用 BIGINT IDENTITY。
- 金融数据最终存储不得使用浮点数，按 `DEC-008` 的 `NUMERIC` 精度保存。
- 敏感数据采用信封加密；主密钥不得进入数据库、代码仓库或镜像。
- 远程登录采用隔离 Chromium 容器、Playwright 和 noVNC。
- MVP 不开放任意 URL，只支持域名白名单和已实现连接器。
- 数据提取优先级：官方 API > 网络请求 > HTML 表格 > 下载文件 > OCR；OCR 必须人工确认。

完整决策以 `docs/DECISIONS.md` 为准。
