# 验收标准

## 1. 验收原则

- 验收以可重复证据为准，不以“页面可打开”代替正确性。
- 每项需求至少关联一个自动测试、人工检查或运行证据。
- 统计测试使用固定输入、明确口径和期望输出。
- 安全和回滚失败属于阻断问题。
- 未确认事项不能以开发人员默认值通过验收。

## 3. 全局完成定义

任何实现阶段只有同时满足以下条件才可完成：

- 功能需求和错误路径已测试。
- 数据库迁移可升级，并有回滚或前滚恢复方案。
- OpenAPI 已更新，破坏性变化已评审。
- 日志、指标、审计和告警覆盖关键路径。
- 权限、敏感数据、限流和输入边界已测试。
- 所有业务表、仓储、任务、缓存和对象访问包含 `workspace_id` 隔离。
- 文档与实现一致。
- 无未关闭的阻断级缺陷。

## 4. 身份与权限

- 每个 MVP 用户创建且只能访问一个个人 Workspace；不存在共享和邀请入口。
- 首次初始化仅在系统无用户时可用；请求必须校验 `BOOTSTRAP_TOKEN`；管理员、个人 Workspace 和 Owner 关系必须在单一事务中创建；并发初始化只能一个成功。
- 客户端传入、篡改或猜测 `workspace_id` 不能切换 Workspace。
- 对所有 UUIDv7/BIGINT 业务资源执行跨 Workspace 测试，返回结果不泄露资源是否存在。
- 系统管理员不能仅凭管理员角色读取其他个人 Workspace 的业务数据。
- 正确凭据可登录；错误凭据不会泄漏用户是否存在。
- 登录后 session 轮换；退出和管理员撤销立即失效。
- 过期、撤销和伪造 Cookie 均被拒绝。
- 所有有副作用的接口在缺少或伪造 CSRF token 时被拒绝。
- `viewer` 无法写入；`analyst` 无法管理用户或密钥；资源范围隔离有效。
- 密码、Cookie、API Key 不出现在数据库明文字段、响应、日志和审计 JSON。

## 5. 时间、数值和数据模型

- 所有时间点以 UTC `timestamptz` 持久化，默认业务显示时区为 `Asia/Shanghai`。
- 所有 Workspace 业务表启用 RLS；业务事务使用 `SET LOCAL` 设置当前 Workspace，Repository 查询仍显式包含 `workspace_id`。
- 市场数据同时保存 `trade_date` 与 `session_type`；夜盘样例按对应交易所日历归入下一交易日。
- 交易日历按交易所版本化，人工修正保留前后值、理由和操作者。
- `close_price` 与 `settlement_price` 独立保存，分析和图表响应包含 `price_basis`。
- 数据库 schema 校验 `price/spread=numeric(20,8)`、`money/fee/pnl=numeric(24,4)`、`ratio=numeric(20,10)`、`lots=bigint`。
- 普通业务实体主键为应用层 UUIDv7；高频时间序列和明细为 BIGINT identity，并具有包含 `workspace_id` 的业务唯一约束。
- `currency_code` 默认 CNY；MVP UI 不允许选择其他币种或触发汇率换算。

## 6. 导入

- TXT、CSV、XLS、XLSX 至少各有正常、边界和恶意样例。
- UTF-8 和批准的中文编码可正确预览；检测失败可人工选择。
- 映射预览显示原始值、规范值、错误和目标字段。
- 文件内重复与数据库冲突分别统计。
- `skip`、`overwrite`、`abort` 在允许的数据集上符合定义。
- 同一文件和参数重试不会重复写入。
- 无后续修改和依赖时，回滚新增和覆盖行后数据与导入前一致。
- 任一后续修改或下游依赖存在时，整个回滚零变更并返回完整冲突。
- 系统无部分回滚入口；纠错通过带 `compensates_batch_id` 的补偿批次完成。
- 导入批次、staging、错误和正式行全部受 Workspace 隔离。
- 超大、伪造、压缩炸弹、公式和外部链接样例安全失败。

## 7. 套利与统计

- 5A 三禾自由价差与 5B 自有库套利监控分别由独立 Evaluator 验收；详细门禁以
  `docs/phases/PHASE_05_SPREAD_ANALYTICS.md` 为准。
- 三禾只允许服务端访问 `DEC-042` 的三个 POST 路径；任意实际请求间隔至少 1.5 秒，
  同参数当日持久缓存，前端无直连并显示“数据来源：三禾数据”和取数时间。
- HTTP 200、`code:0`、空 data 是合法空结果；网络/HTTP/业务/字段错误稳定区分，
  cache miss 不自动重试，不用过期缓存冒充当日数据。
- 三禾点按实际两腿合约、本库交割月和版本化散户窗口裁剪；跨年、晚上市、品种规则
  覆盖、段界、不可交易月和部分月 fixture 与人工结果一致。
- 季节图与月度矩阵只从裁剪后序列重算；污染三禾 `year_data/stat_ret/stat_rate`
  不改变用户结果。
- 两腿、三腿、负系数、非零常数样例计算正确。
- 每个 `spread_observation` 可下钻到公式版本和原始腿价格。
- 缺失腿、重复来源、非交易日和不同价格类型不被静默混用。
- 百分位、Z-Score、均值、中位数、标准差的定义和样本数可见。
- 季节性在跨年区间、闰日和不同交易日历下符合确认口径。
- 公式或参数变更生成新版本，不修改旧结果。
- 行情图默认使用收盘价；非默认口径必须显式选择并显示。
- 日终持仓、未实现盈亏和权益默认使用结算价。
- MVP 不存在规则驱动历史回测、模拟成交或自动信号接口。
- MVP 不执行连续合约生成；外部连续合约显示来源和换月规则且不与实际合约混用。
- 5B 只有短样本时如实显示有效区间、样本数和数据不足，不声称不存在的五年分位；
  经验分位、Z 值、极端阈值和近 60 个有效交易日 sparkline 可复算。

## 8. 图表

- 过零点插值后正区间红色、负区间绿色，连续性正确。
- 0 轴、当前值虚线、右侧标签、背景区间和水印符合模板。
- 缩放、悬停、时间范围和空数据状态可用。
- PNG 与 SVG 均由 ECharts 前端直接导出且内容一致；不存在服务端图表渲染服务。
- SVG 安全清洗后无脚本、事件处理器和外部危险引用。
- 图表导出和保存记录包含 `workspace_id`、`price_basis`、交易日历版本和来源。

## 9. 成交与持仓

- 原始 `trade_fill` 不可覆盖修改；纠错记录通过引用原成交的冲销/补偿完成。
- FIFO 配对结果可下钻到开仓成交、平仓成交、分配手数和分配顺序。
- 完整交易组的胜率、盈亏比、期望收益和 Profit Factor 与人工样本一致。
- 最大回撤基于确认的权益口径，峰值和谷值可定位。
- 部分平仓、费用、平今/平昨、跨日和多腿交易按确认规则处理。
- 未完成交易组不进入胜率。
- 胜率按完整 `trade_group` 而不是单笔成交计算。
- 已实现净盈亏使用实际成交价并包含手续费；加权平均只作为当前持仓成本展示。
- 每日持仓快照不被用于虚构无法确定的成交配对。

## 10. 席位

- 原始名称到标准席位的解析有来源和有效期。
- 分类包含版本、证据、可信度和有效期。
- 前 N、集中度、净持仓和变化可由原始行复算。
- 页面和导出使用“倾向”表述，不使用无证据身份断言。

## 11. akshare 自动采集

- API 不接受任意 URL；采集容器只允许访问 DCE、SHFE、CZCE、GFEX、CFFEX 的交易所域名白名单，外加 `DEC-041` 的新浪域名与 `DEC-043` 的 `datacenter-web.eastmoney.com`。东方财富仅按 `DEC-043` 作为席位专用兜底源接入（排在全部官方源之后，不承担行情与目录），其余二手数据源不进入第一批。
- 非 http/https、localhost、私网、链路本地、云元数据和 DNS Rebinding 目标被拒绝；每次重定向重新校验。
- 采集容器无法访问宿主机文件、数据库、对象存储、Docker socket 和管理端口，标准化 CSV 只通过导入 API 提交。
- 白名单结构化自动采集批次使用固定映射模板版本，免人工确认、免提取预览；手动文件导入的既有 preview/confirm 流程不变。
- 解析或校验失败的自动批次隔离为 `failed`，正式表零写入；数据质量警告被记录但不阻断成功批次。
- 同一数据源、采集范围和版本重复执行或任务重试不会重复写入正式数据。
- 正式记录可追溯到交易所数据源、采集任务、标准化 CSV、导入批次和变更日志；成功批次可按既有契约整批回滚。
- 全市场日行情执行全部可得历史的一次性全量回填；全市场席位龙虎榜先回填近 5 年，再由后台任务倒序向更早年份补拉。
- 历史回填支持断点续跑；不可得年份保留明确记录且不阻塞其他年份或数据集。
- 磁盘达到 80% 水位时触发扩容 VPS 磁盘的运维流程，不更换机器。

## 12. 信封加密

- 数据库只保存密文、`wrapped_dek`、`kek_version` 和算法元数据，不保存主密钥。
- 主密钥不存在于数据库、代码仓库、Docker 镜像和普通日志。
- 主密钥轮换可只重新包裹 DEK；轮换前后业务密文可正确解密且 `kek_version` 更新。
- 数据库备份不包含主密钥恢复副本，两者访问控制和存放位置分离。
- 解密操作校验 Workspace 和用途，跨 Workspace 复制密文不能成功解密。

## 13. AI

- AI 只能看到当前用户有权访问的数据。
- AI 对话、工具调用和来源严格限制在当前 Workspace。
- AI 无通用 SQL、文件、URL、shell 或写工具。
- 固定问题集中的数值与确定性工具结果一致。
- 每个回答含 `data_cutoff_at`、样本区间、排除规则和来源。
- 行情、价差、持仓和盈亏回答包含 `price_basis` 与交易日历版本。
- 网页/文件中的提示注入不能改变工具策略或获取秘密。
- 超时、限流、Provider 不支持工具和流中断有明确状态。
- token、费用、模型和工具调用审计完整且脱敏。

## 14. 任务、备份与运维

- Worker 崩溃后租约过期，任务可由其他 Worker 安全接管。
- 任务、幂等键、事件流和死信重放全部绑定 Workspace。
- 重试、超时和重复事件不会重复正式写入。
- 达到最大尝试次数后进入死信并可人工重放。
- 备份恢复得到一致的数据库、对象文件和密钥版本。
- 恢复演练达到已确认的 RPO/RTO。
- 磁盘、连接池、任务失败、备份失败和会话过期告警可触发。

## 15. 证据格式

每个验收项记录：

- `requirement_id`
- `test_id`
- `environment`
- `input_fixture`
- `expected_result`
- `actual_result`
- `evidence_path`
- `reviewer`
- `reviewed_at`

涉及统计的证据还必须记录公式/算法版本、精度和样本范围。
